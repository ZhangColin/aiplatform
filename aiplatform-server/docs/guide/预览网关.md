# 预览网关（dev/prod：子域路由 + 圈注注入）

平台预览经 nginx 网关按子域路由到工作区容器，并在 HTML 里注入圈注脚本。开发用
`*.localhost`（浏览器原生解析到 127.0.0.1、关 TLS），生产用 `*.preview.{domain}` +
wildcard 证书——同一份配置，只差 base 域名与 TLS。决议正本见 ADR-0014。

## 架构

```
浏览器 → http://{id}.localhost/          (macOS 把 *.localhost 解析到 127.0.0.1)
        ↓ (port 80)
nginx 网关（server_name ~^(?<wsid>[0-9]+)\.localhost$）
        ↓ resolver 127.0.0.11（Docker 内置 DNS）→ 按容器名解析
ws-{id}:8081（工作区容器，previewnet 同网，无宿主端口映射）
```

- 路由：一条通配 server 块吃所有项目——`{id}` 从 Host 捕获，`proxy_pass http://ws-$id:8081`，零 per-app 配置、零 reload。
- 注入：`sub_filter` 把 `</head>` 换成 `<script src="/.aiplatform/annotation.js">` 引用；脚本资产由网关自持（`location = /.aiplatform/annotation.js`），不进用户源码、不在容器内。
- 收口判据不变：容器内 8081 探活（`curl localhost:8081`），与网关无关。

## 开发启动

后端置备工作区时会幂等 `docker network create previewnet` 并让容器进该网络。网关手动起一次：

```bash
docker run -d --name aiplatform-gateway \
  --network previewnet \
  -p 80:80 \
  -v "$PWD/src/main/resources/docker/gateway/nginx.conf:/etc/nginx/nginx.conf:ro" \
  -v "$PWD/src/main/resources/docker/gateway/gateway-route.conf:/etc/nginx/gateway-route.conf:ro" \
  -v "$PWD/src/main/resources/docker/workspace/annotation.js:/etc/nginx/annotation.js:ro" \
  nginx:stable-alpine
```

验证（`42` 换成真实 workspaceId，工作区应用已在 8081 起服）：

```bash
curl -H 'Host: 42.localhost' http://127.0.0.1/ | grep -o 'data-aiplatform="annotation"'
curl http://42.localhost/.aiplatform/annotation.js | head -c 80   # → 标注脚本文本
```

改配置后 `docker exec aiplatform-gateway nginx -s reload`（零重启）。

## 生产（#129：wildcard TLS + 域名）

同一份路由/注入块，base 换 `*.preview.{domain}`、监听 443 + wildcard 证书（TLS 终止），
80 强制跳 https。后端 `app.workspace.preview-base` 切为 `preview.{domain}`、
`preview-scheme` 切 `https`（`WorkspaceNaming.previewUrl` 已把 scheme 参数化），预览
URL 即 `https://{id}.preview.{domain}`。

### 1. wildcard 证书（certbot dns-01）

DNS-01 校验签 `*.preview.{domain}`（dns 插件按域名服务商选，示例用 Cloudflare；
`--cert-name preview-gateway` 固定 live 路径，与 nginx 配置对齐）：

```bash
certbot certonly --dns-cloudflare --dns-cloudflare-credentials ~/.secrets/cloudflare.ini \
  --cert-name preview-gateway \
  -d '*.preview.example.com' \
  --non-interactive --agree-tos -m ops@example.com
```

证书落 `/etc/letsencrypt/live/preview-gateway/{fullchain,privkey}.pem`；续期由
certbot 定时器自动完成，续期后 `docker exec aiplatform-gateway nginx -s reload`
热载新证书。

### 2. 生产 nginx 配置（同一 server 块 + TLS 终止）

模板 `src/main/resources/docker/gateway/nginx.prod.conf.template` 只含一个模板变量
`${PREVIEW_DOMAIN}`，用 `envsubst` 只替换它（放行 nginx 自身 `$host`/`$upstream`/`$wsid`）：

```bash
PREVIEW_DOMAIN=preview.example.com \
  envsubst '${PREVIEW_DOMAIN}' \
    < src/main/resources/docker/gateway/nginx.prod.conf.template \
    > /tmp/nginx.prod.conf
```

起网关（挂生产配置 + 标注脚本资产 + letsencrypt 证书目录，宿主 80/443）：

```bash
docker run -d --name aiplatform-gateway \
  --network previewnet \
  -p 80:80 -p 443:443 \
  -v /tmp/nginx.prod.conf:/etc/nginx/nginx.conf:ro \
  -v "$PWD/src/main/resources/docker/gateway/gateway-route.conf:/etc/nginx/gateway-route.conf:ro" \
  -v "$PWD/src/main/resources/docker/workspace/annotation.js:/etc/nginx/annotation.js:ro" \
  -v /etc/letsencrypt:/etc/letsencrypt:ro \
  nginx:stable-alpine
```

### 3. 后端 prod profile

`application-prod.yml` 已设 `app.workspace.preview-scheme: https`，base 经环境变量
`PREVIEW_BASE` 供给（无默认，缺省启动即 fail-fast）：

```bash
PREVIEW_BASE=preview.example.com SPRING_PROFILES_ACTIVE=prod java -jar aiplatform-server.jar
```

验证（`42` 换成真实 workspaceId，工作区应用已在 8081 起服）：

```bash
curl https://42.preview.example.com/ | grep -o 'data-aiplatform="annotation"'
```

多节点/公网 LB/TLS 终止等单机外拓扑见 ADR-0014 备案。

## 范围

只覆盖主工作区容器（dev 预览）。「查看当时」快照容器（#92）是独立临时视图、仍走
各自随机端口，不纳入网关。

## 圈注协议不变

注入脚本与 `aiplatform-web/src/lib/preview/annotation.ts` 同源（postMessage 信封
`{ __aiplatform__: true, type: "annotate"|"anchor" }`）；前端校验 `event.origin` =
预览 URL 的 origin，子域 origin（`http://{id}.localhost`）照常成立——前端零改动。
