# 生成复杂度治理与验证让路速度

Demo 首建提速的复杂度治理定档（承 wayfinder 地图 #510「生成哲学一统」锁定共识、决议正本＝#516，策略以 #511 竞品取证为凭——速度主战场在预置与范围、不在模型档位，模型面零改动）。两件事：**信息量定深度**（实现深度跟采集到的信息量走、杜绝臆想加戏——协议语文化落点）与**验证让路速度**（#446「质量机制不砍」锁改判：三硬底线是唯一不让路的质量面，验证机制皆可让路）。承 ADR-0009（纵向切片、每片端到端——治理的是宽不是深，无需补记）；#427/#406 整轨终验机制保留、开关现状不动。

## 决策

**收口判据改三硬底线语义（执行体协议条 3 改写）**：撤除「真实应用不是静态页面」的厚度指令——收口语文化为三硬底线：能打开不白屏（8081 常驻＋入口文件完整＝探活三件套）、刷新不丢（核心操作真实落库）、核心路径可点（核心旅程主径走通）；「带数据库」从判据降为手段（刷新不丢的承载，基座本就自带）。丰富感来源语文化：演示数据真实感、反对 placeholder 文案（对齐 Lovable/Replit 官方口径，#511）——示意级≠假大空，而是真实感内容＋浅持久化。

**示意级边界与显式推迟清单**：统一边界原则＝**界面走得通、数据真落库、外部副作用为零**。切片计划产出协议（主智能体面）加结构化推迟段、随 PRD 版本落库：默认集聚焦业务向——支付（下单/结算流程界面可走通、停在不真扣款）、通知（站内呈现、不发真实推送/邮件）、多角色权限（按单角色直做）；外部集成在 PRD 明确涉及时按需列入；技术类条目（性能优化/安全加固）不预置——它们正是「用户不可见的加戏」典型，由总句治理。信息量不足的功能（访谈没问出来的）进推迟清单而非执行体拍脑袋做。执行体侧只加消费句「清单内不做、不自行加回」；平台不加机器闸（协议约定，对齐竞品「Do not add … yet」写进 prompt 模板的机制定位）。

**片数跟信息量走＝协议软引导**：主智能体协议引导「信息量少＝清单长＋片少、每片端到端完整点（深由 ADR-0009 保证，治理的是宽）、典型 3-5 片收口成版」；不设结构校验硬门（#416 批次失控前科——数值门误设），锚案例对照不达再议硬门。

**待定项缺省做薄（协议条 1 改写）**：「待定项按合理缺省实现」→「按**最小可用**缺省实现并在收尾说明」——缺省方向从做厚转为做薄，够走通主径即可（#449 后 PRD 面已推荐答案补全，剩到执行体的待定项是字段级零碎；整功能信息量不足走推迟清单）。

**演示数据维持执行体自建＋语文化**：数据一轮建成（首片建表即灌，不铺开到后续片）、真实感、不追求全实体覆盖；零新机制。不前置到 PRD/访谈期——数据与表结构强耦合、前置产会错位（执行体还得翻译适配），五问信息量少的项目前置产数据同样是臆想、只是换了便宜轮次。对照轮顺带归因「造数据轮次占比」，有数据再议前置形态。

**验证面让路速度（分层）**：
- **机器探活三件套**（8081 探活＋入口文件完整＋git 成版）永留——秒级确定性、零 LLM 轮次、唯一收口硬判据，「能跑」由它硬保；
- **片验自决砍**：运营面关 `verify_self_decision_enabled`（#442 开关已备、零代码不发版）＋执行体协议条 9 撤回「拿不准的片建议验」的自决建议（避免与开关注入指令打架）；执行体开发过程中自查页面可打开照常保留——那不是验证税（终裁实测 verify 窗 20.9min、真实独占估 12-15min、6/7 段被拉起）；
- **整轨终验维持关**：`final_verification_gate_enabled` 维持 #435 起缺省关——上周实测终验是时间杀手、比逐片验还长（终验 run 编排＋fail→修复→复走循环），运营面可开、机制与代码不动；
- **残余风险＝有意识取舍**：终验关后「核心路径可点」（跨片断点/页面间链接/按钮真响应）无机器防线，防线＝执行体自查＋用户实时看着预览（demo 阶段用户在场即验收，断了对话区提意见走迭代轨修）。

**渐进呈现零改、如实留痕已同构**：阶段 0 起服空白页＋逐片增量＋preview-ready 推 URL＋update_plan 步骤清单＋对话区里程碑，对照 Stitch（流式直绘）与 AI Studio（代码流式、预览即跑）机制已同构（平台确定性刷新单元比竞品 prompt 级更硬）；片内中间态可见与步骤呈现增强出界留 backlog——不是 1.5h→60min 缺口的主因。

**验收协议**：锚案例（背词记忆管家）重触发对照，≤60min＝红线验收门（实施切片全落地后不进带＝回议不收口）、≤30min＝方向指引不阻断；对照协议沿用 #432 生产复演路径（eu-1 重触发、报告落 docs/research/）；实施前先补 #442/#443 后基线（欠账未跑，最新数据仍是 11-10 终裁 1h30m），否则归因不净；实施后一轮总效果对照、不逐项拆跑（每轮 1.5h+）。

## Considered Options

- **PRD 附演示数据集（数据面前置到 PRD/访谈期）**——否决（用户裁定）：数据是实现期的事；与 schema 耦合前置产会错位；五问信息量少、前置产同臆想。执行体自建＋语文化先行，对照归因后再议。
- **整轨终验翻开为「系统不能用」防线（验证重心从逐片移到旅程轴）**——否决（用户裁定）：上周实测时间杀手、加了比每片验还长；「能不能跑」已由探活＋开发过程自查确保，核心路径可点由执行体自查＋用户实时预览承载。
- **领域内容包前置（访谈期沉淀纯内容素材、执行体自行映射）**——暂缓：省「想内容」轮次但新携带字段＋映射适配是发明机制、无实测归因支撑（「造数据占多少轮次」无数据）；对照轮归因后再议。
- **片数结构校验硬门（超区间拒计划）**——否决：#416 批次失控前科（数值门误设）；切片数量是 PRD 结构的涌现结果非平台旋钮，软引导保住涌现性质。
- **推迟清单平台机器闸（收口校验清单项未做即拦）**——否决：清单是协议约定非机器闸（竞品形态＝写进 prompt 模板）；机器闸与「验证让路速度」自相矛盾。
- **技术类条目进推迟清单默认集（性能优化/安全加固）**——否决（用户裁定）：默认集聚焦业务向；技术类加戏由「用户不可见的不做」总句治理，不预置条目。
- **渐进呈现改造（片内流式直绘/步骤呈现增强）**——出界 backlog：现状已同构且更硬；不是缺口主因。
- **模型面改动（降档/换模型）**——否决：#511 取证四家竞品无一靠模型档位换首版速度，本平台 flash 全量＋失败升档已同构。

## Consequences

- 执行体工作协议改写（`AgentProfile` EXECUTOR systemPrompt：条 1 待定项句、条 3 三硬底线判据＋数据一轮建成句、条 9 撤回自决建议＋推迟清单消费句）＋主智能体切片计划产出协议（结构化推迟段＋业务向默认集＋片数软引导）＋ prd-writing SKILL.md 校对——实施切片①（票内清单、不建票）。
- 运营面动作：`verify_self_decision_enabled` 关（运营配置、零代码不发版、进行中 run 不定格）；`final_verification_gate_enabled` 不动——实施切片②。
- 对照轮：先补 #442/#443 后基线 → 实施后总效果对照（锚案例、生产 eu-1 重触发、报告落 docs/research/、≤60min 红线门）——实施切片③。
- CONTEXT.md：新增「示意级」（业务语言区）、「推迟清单」（平台内部语言区）词条；「生成」「整轨终验」相关词条的现状描述句随实施切片同步改写（词条不超前于代码）。
- #446「质量机制不砍」锁改判正本落此：重述为「三硬底线是唯一不让路的质量面；验证机制（片验自决/整轨终验）皆让路于速度」——票内留痕评论随 #516 决议。
- ADR-0009 无需补记（纵向切片语义不变）；#427 终验机制保留、开关缺省不动；#435 自决化缺省值不动（运营态关）。

## 补记（2026-11-16，#517 lint 让路延伸）

验证面让路的范围延伸到基座 lint 修轮面：基座强制档（拦裸写）从「阻断＋修轮＋失败链」降级为「收口照扫、违规如实标注」（补运营开关保险）；修轮触发面收窄至样式合规（设计规范 lint 既有软形态不动）。「能打开不白屏」仍由机器探活三件套硬保；裸写超时缺失＝有意识取舍的残余风险（用户裁定「只要不影响系统呈现体验」）。见 ADR-0051。
