# Triage 标签

各 skill 以五个规范化 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 的标签 | 含义                       |
| -------------------------- | ------------------- | -------------------------- |
| `needs-triage`             | `needs-triage`      | 待维护者评估               |
| `needs-info`               | `needs-info`        | 等待报告者补充信息         |
| `ready-for-agent`          | `ready-for-agent`   | 规格完整，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`   | 需要人来实现               |
| `wontfix`                  | `wontfix`           | 不予处理                   |

当 skill 提到某个角色（如"打上 AFK-ready triage 标签"），使用表中对应的标签字符串。

按需修改右列以匹配你们实际使用的词汇。
