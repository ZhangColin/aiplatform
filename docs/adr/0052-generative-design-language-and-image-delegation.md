> **改记（2026-11-23，从零重设收尾）**：出局——风格方向库／物化链／规范三件套全出局；前提「模型审美不可靠」被第一手反证推翻（机制压制设计实测、同模型裸写自主深色科技风）；「跨项目风格趋同」在本平台未被观察到、风格引导不进（PRD 风格词为锚）。出图工具件降回必配能力清单、逐件过准入标准。正本见 ADR-0055（#581）、ADR-0054。

# 每项目生成式设计语言与系统轨出图下放

生成「快与美」的风格面定档（承 wayfinder 地图 #510「UI 美化研究后裁」子域、决议正本＝#518；证据以 #512 四路取证为凭——竞品无一家靠模型审美或随机化，「好看」外置为 Tailwind+shadcn 基座＋校验闭环、「不千篇一律」外置为多套可换的风格层；v0 官方实验两面证：不挂系统＝调色板散架的随机 slop、挂不同系统＝同 prompt 完全不同风格，「统一规范致千篇一律」在规范层多套可换前提下被证伪）。两个裁决面：**UI 美化路线主押与组合**（四路候选：生成式设计语言/平台默认语言族/第三方设计 skill/模型面）；**图片能力下放**（ADR-0026 备案触发器，#517 划入本票）。

## 决策

**主押＝每项目生成式设计语言（三件套扩来源）**：项目首建 PRD 期由主智能体产风格方向 → 平台确定性物化为设计规范双件（机器可读 token＋人读规则），此后三件套照常——写入/注入/扫描/收窄全复用、遵守机制零新建（三件套只吃「规范文件」输入、与来源解耦，#512 §2 实锚）。Stitch「配色先行」、Lovable「Get the design right first」同构。「平台默认设计语言族轮换」不作独立路径——无项目级差异、防单调能力有限；其正确形态是主押的底座。

**风格方向库（底座）**：平台侧预置的方向集合，每套＝token 值集（色板/字体对/圆角/阴影/密度）＋人读规则句，双件同构设计规范。模型只在库内选/微调、不从零凭空配色（防生成式规范质量不可靠——Lovable 20 方向同构对策）。首批 8 套含缺省套（领域气质谱系覆盖），扩容＝运营动作（同健壮件「增补＝运营动作」通道）、盘点轮数据校正；维护＝平台常量随发版（同栈规则集形态），不进基座镜像（基座只收每项目物化后的 token 值）；准入＝人审＋WCAG 对比度一次性机械校验（建库工具脚本，不进运行时）。建库素材可参考 taste/uupm 公开数据（均 MIT、人读一次性参考、零安装零运行时依赖）。

**选取机制＝模型代选＋对话可改**：主智能体写 PRD 时从方向库目录选定（可按 PRD 领域气质微调参数），内嵌 PRD 撰写同一轮产出——不加轮次、不占五问额度、零新交互面（速度优先）；所选方向名呈现在 PRD 关键约束节（如「风格方向：清新教育」），用户看得见。改走对话（「想要更沉稳」→ 意见受理 → PRD 修订 → 重物化 → 构建对齐），全部既有语义零新通道。theme selector 式用户可感选择 UI 后置为未来产品动作（机制已留、加壳即得）；可视化微调面（Visual edits）同后议（圈注通道已有意见承载）。

**物化时点与全域生效**：PRD 定格/首个构建派发前，平台读 PRD 风格方向字段 → 库值映射 → 确定性写基座（非模型动作，物化缝既有）；失败/字段缺失落库中标记的缺省套兜底。生效面＝新项目全量（现状设计入口收起后本就无规范习惯、无误伤面），存量项目不迁移（地图共识）；带运营 kill-switch（关＝回无规范现状，#442/#517 开关保险同款）。

**防千篇一律的机制答案**：方向库多套（项目间不同）＋每项目选定物化（项目内一致）＋模式件零主张（ADR-0051 换装衔接面——预置件只吃语义 token，风格层落地后零改动自动吃上新语言）。「不散架的不单调」。

**第三方设计 skill 不进本期（定位＝后手）**：不装 taste（Node22＋本机 Chrome＋Stop hook 依赖＋官方自述单次构建 30-45 分钟＝直接撞 ≤60min 红线，另有 2.5× 成本负面盲测个例）；不装 uupm 运行时（新缝、注入面审核成本）。用户裁定：风格层落地后看效果，效果不佳再考虑安装（#512 已查明两者形态/许可证/代价可行面）。

**模型面仅核查不押注**：对照轮班次顺带核对 flash 档实际指向的模型版本（运营面一行查询不发版；若仍指旧世代，升档本身即有官方声称与榜单佐证的美观改进）。本期不换模型、不开 A/B——预期管理＝规范注入把 DeepSeek 拉到「可控、可上线的合格审美」，不追平 Claude 头部（80-140 Elo 是默认态差距，注入后差距不可预期）；风格层落地后人眼仍不满再开 A/B（通道现成，留而不排期）。

**图片能力下放（ADR-0026 备案触发器兑现）**：触发——出图工具件发放面从设计执行体扩到系统轨构建执行体（AgentToolkitSupplier 既有缝、模型面白名单仍零改）。协议用途句约束＝演示数据配图（首屏 hero＋关键实体图/空态美化，服务 ADR-0050「真实感反 placeholder」语义）、「少而精」总量个位数、不逐卡片配图——无机器张数上限（对齐「平台不加机器闸」，执行体按页数自然有界）。档位＝快档起步（智谱 CogView-4，0.06 元/张、生成快），质量不满运营面升档（单价表换行零机制）；按张计量事件、24h 即时转存全沿用（ADR-0026）；用户计费面＝固定单价项族（ADR-0047 小价目同型）。速度控制＝协议引导＋快档＋计量归因＋运营开关（关＝构建执行体不发图工具，回无图现状）。

**班次与刀序**：与 ADR-0050 切片①（协议改写）动同一批文件——刀序串行防冲突：#516 切片①先落、风格层紧随。对照进 ADR-0050 对照轮同班次（其验收本就是「实施后一轮总效果对照」），速度归因靠计量面单拉（图片张数×耗时）；美观/多样性验收＝用户人眼（「像不像」归用户人眼既有口径，不进机器红线），千篇一律观察＝多项目人眼＋盘点轮风格分布。

## Considered Options

- **平台默认设计语言族独立轮换（候选 B 独立成路）**——否决：无项目级差异、防单调能力有限；正确形态＝并入主押作方向库底座。
- **模型凭空配色、不用方向库**——否决：生成式规范质量不可靠（模型产的配色/字体组合可能不和谐）；业界对策一律是「预设方向库＋模型在其中选/微调」（Lovable 20 方向）。
- **用户可感 theme selector 先行（Stitch 式）**——否决（本期）：demo 阶段新交互面成本、速度优先；模型代选内嵌 PRD 撰写零额外轮次零新界面；selector 后置产品动作、机制已留。
- **五问里占一问选风格**——否决：挤占五问额度（#514）；模型代选不占额度。
- **安装 taste**——否决（本期）：Node22＋本机 Chrome＋Stop hook（本平台技能体系无 hook 对应物）＋官方自述单次 30-45 分钟撞 ≤60min 红线；2.5× 成本负面盲测个例；定位改判后手。
- **安装 uupm 运行时**——否决（本期）：新缝与注入面审核成本、star 数≠真实使用质量（无独立盲测）；其公开数据（192 色板/74 字体配对/80 风格）可作建库素材零安装。
- **换更美学模型/开「注入有无×档位」A/B**——否决（本期）：档位差是默认 prompt 下的盲测差距、注入后不可预期；规范注入对任何模型都适用；通道留而不排期（人眼仍不满再开）。
- **图片不真出图（icon 库/inline SVG/占位形态承载）**——否决：placeholder 恰是 ADR-0050 演示数据语文化要反的对象；竞品「丰富感」实证来源含图片；机制零新建成本下值得直接触发（用户裁定：没有图片太单调）。
- **图片张数机器上限**——否决：对齐「平台不加机器闸」（ADR-0050）；协议句引导＋页数自然有界＋计量归因。
- **可视化微调面（Visual edits）**——出界后议：圈注通道已有意见承载；Lovable/Bolt 形态留参照。

## Consequences

- 实施切片三片（票内清单、不建票）：①风格方向库首版（8 套含缺省套＋建库校验工具一次性）＋物化通道（PRD 风格方向字段→库值映射→写基座）＋协议改写（主智能体 PRD 协议＋prd-writing SKILL 增风格方向产出；目录经 systemPrompt 动态装配注入、库正本单源在平台常量）＋三件套全域生效＋kill-switch；②图片能力下放（发放面扩构建执行体＋协议用途/少而精句＋快档起步＋运营开关）；③对照与观察（同 ADR-0050 对照轮班次：总效果＋图片张数/耗时计量面拉数；人眼美观/多样性观察；盘点轮顺带风格分布）。
