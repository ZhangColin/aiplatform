## What to build

项目详情工作台从两栏升级为三栏通用层 D 壳（spec 0001 §3）：左 Agent 区（默认 380px / 最小 260px，collapsible）+ 中主面板 tabs（最小 320px）+ 右阶段·任务面板（默认 320px / 最小 220px，显式图标开关收起 → 两栏态）。顶栏常驻 LIVE 脉冲 + 计时 + 终止按钮（UI 就位，动作待后端终止端点，见 spec 缺口）。<1024px 退化为三页签（对话 / 工作区 / 阶段），顶栏运行状态保留。Agent 区三模式 tab 骨架（对话 / 直播 / 待处理）就位但内容占位；需求端配置 = 顾问单对话模式（不显示直播 / 待处理）。此票只落壳，不落任何业务内容——业务内容由后续票填。

## Acceptance criteria

- [ ] 三栏可拖拽调整宽度，右栏可显式开关收起为两栏态
- [ ] 顶栏显示项目名 + 阶段徽章 + LIVE 计时 + 终止按钮（占位）
- [ ] <1024px 退化为三页签，顶栏运行状态保留
- [ ] 需求端（用户）只显示对话单模式，开发平台显示三模式 tab
- [ ] 无回归：现有主面板 tabs（文档 / 任务 / Bug / 直播）与右栏内容在三栏内正常呈现
