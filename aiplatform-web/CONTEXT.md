# aiplatform-web 前端

AI 开发平台的前端门户（Phase A：三门户）。业务术语（项目/期/门/任务/HITL 等权威定义）以后端仓库 `aiplatform-server/CONTEXT.md` 为准，本表只收前端侧术语。

## Language

**门户（Portal）**:
平台的前端入口分区。v1 三门户：需求端（user）/ 开发平台（dev）/ 任务平台（opc），另有 [[简易后台]] 页（`/admin`，2026-08-25 增）；正式管理后台（admin）门户建时加。场景壳按 `components/{user,dev,opc}-portal` 分目录留拆分缝（URL 段 `/`、`/dev`、`/opc` 承载场景）。
_Avoid_: 端（后端 glossary 的「四门户」含 v1 不建的 admin）

**简易后台（Admin Lite）**:
v1 的轻量管理面：`/admin` 单页起步（引擎配置），门户切换器第四项进入，全账号可见（v1 无角色体系）。定位 = 配置项与后台可见内容的临时聚合地，将来整体迁入正式管理后台（admin）门户。
_Avoid_: 管理门户（正式 admin 建时才有）、设置中心

**工作台（Workbench）**:
操作单个项目的 Replit 式三栏界面（Agent 对话区 + 主面板 tabs + 呼出面板）。通用层组件，各门户场景配置（开发平台 = 对话/直播/待处理三模式；需求端 = 顾问对话单模式）。spec 0001/0002。
_Avoid_: IDE、编辑器、控制台

**通用层 / 场景层（Shared Layer / Scenario）**:
主 Layout（菜单框架）、工作台框架、Agent 对话区、预览、文档面板等与场景无关的通用能力 = 通用层（全平台一套）；门户/功能点作为场景只决定放什么、放哪里、什么文案口径——菜单内容亦归场景（场景菜单）。spec 0002 §1、spec 0003 §1。
_Avoid_: 门户各搞一套 Layout

**场景菜单（Scenario Menu）**:
门户级的菜单内容配置（框架 = 切换器 + 分组结构 + footer，归通用层）：需求端 = 项目相关；开发平台 = 全量；任务平台 = 我的任务 + 待办中心。切换器选门户 = 菜单 + 落地页一起换；将来按角色过滤、拆前端项目挂此配置。spec 0003 §1。
_Avoid_: 全平台一份菜单（T6 作废的旧口径）、角色菜单（v1 无角色，按门户不按人）

**用户侧六步 / 旅程（Journey）**:
需求端用户视角的主链呈现：聊需求 → 看原型 → 制作中 → 质检中 → 验收 → 交付（开发完成门折叠其间不单列）。三扇门 = 确认 PRD / 确认原型 / 验收（「确认需求清单」旧称作废——PRD 用词已放开，2026-08-25）。
_Avoid_: 对用户出现「阶段 / 状态机 / 七步四门 / Demo」字样

**PRD**:
BA 访谈收敛（判定无可追问）后产出的需求文档，用户确认的对象；界面直用「PRD」（2026-08-25 放开），文档 tab 与第一扇门共用此词。v1 单最新版，无版本链。
_Avoid_: 需求清单、需求纪要（旧称，已收敛为一套词）

**agent 直播画面（Agent Feed）**:
智能体执行过程的实时可视化（SSE 事件流渲染：流式文本 / 思考 / 工具调用 / 代码补丁摘要）。
_Avoid_: 干活日志、日志面板

**问答卡（Question Card）**:
智能体 HITL 提问的前端呈现（选项 / 多选 / 自定义输入，答后智能体继续）。开发平台 = 卡片（琥珀描边 + 顶部 badge）；需求端顾问对话 = Replit 式内联（选项为按钮 chip、单选单题点选即答、去卡壳，2026-08-28 落定）。
_Avoid_: 提问弹窗

**审批卡（Approval Card）**:
智能体工具权限请求的 HITL 卡片（允许 / 拒绝 + 终止任务逃生口）。
_Avoid_: 权限弹窗

**决策门卡（Gate Card）**:
主链决策门的前端呈现（通过 / 驳回必填意见并回传智能体）。
_Avoid_: 审批门、关卡

**待办中心**:
双端待办的统一呈现（「待我处理 N 项」：智能体等答复 / 任务待确认 / 可发复测 / 门待拍板 / 新任务 / 被驳回）。决策门与 HITL 等待点分端点、UI 统一呈现。
_Avoid_: 通知中心、消息中心

**预览（Preview）**:
项目环境暴露端口的页面入口，沙箱 iframe 呈现 agent 产物。
_Avoid_: demo 页、演示

**知识命中（Knowledge Hit）**:
阶段开始检索注入历史知识时，在前端的可见化呈现（历史知识卡片）。

**安心卡（Calm Card）**:
需求端「制作中 / 质检中」等无需用户操作环节的状态呈现（不用你操作 + 预计时间），弱打扰。
_Avoid_: 空态、loading 占位

**下一期想法池（Idea Pool）**:
验收/开发中用户新想法的暂存（记入项目，v1 不自动开期）。验收门卡与工作台右栏双入口。
_Avoid_: 需求变更队列（变更走对话必填说明，不进池）

**平台成本（Platform Cost）**:
用量卡上金额的呈现口径：平台为模型调用付出的成本（token × 事件时点生效单价的机械乘法），币种分桶平铺、不相加不折算（无汇率概念）。无加价/售价/账单概念——那是业务层计费，不在本平台。spec 0002 §4。
_Avoid_: 价格、费用、金额（暗示售价的措辞）

**路由守卫（Route Guard）**:
UX 层的登录态检查：middleware 验 `aiplatform_session` cookie 存在性（不透明 id，不验真），缺失则 302 到 `/auth/login` 并携带 returnTo 回跳参数。验真与权威拦截 = 后端 401 全局出口。v1 只验登录态，三门户无差别。spec 0004。
_Avoid_: 权限路由 / 角色路由（v1 无角色）、前端验会话真伪（不透明 id 做不到）

**对接 issue**:
后端一块 swagger 就绪后发给本仓库的执行工作项（直接做，不进 wayfinder 图）。
_Avoid_: 联调单

**罐头流（Canned Stream）**:
UX 原型用的事件样本数据，仅供设计探索。「不 mock」约束的是对接层（不伪造 API 集成），罐头流不违反。
_Avoid_: mock 数据
