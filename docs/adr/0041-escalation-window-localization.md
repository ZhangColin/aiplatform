# 升档窗口局部化：lint 修轮窄修派发、attempt 级窗口，不做迭代级切档

升档时限语义裁决（2026-11-12，#472 用户裁决；承 ADR-0030 模型路由、ADR-0037 仅失败升档、#471 升档诱因消减）。现状事实：路由判定纯计数（attempt>1 无条件升强档）——lint 违规的收口重试与能力面真失败在路由层同形，这是「升档窗口无法局部化」的机制根源；修轮派发文案仍整段重述任务（「完成本段任务」），复演 379071235077138707 同需求重触发（10 段全收口、7 次升档全 lint 族）实证 pro 修轮 92%/92%/67% 级重做整场、三段占 pro 总迭代 75%；而 seg0/4/8/9 同机制下 26-32% 快修形态并存——重做是派发口径问题非必然。定案：

**窗口＝attempt 级**：错误处理中＝强档（修轮 attempt 照旧升 pro），错误解决即闭合——违规清零、收口 PASSED、段即终，下一派段 flash 首试（跨段不继承是现状结构，无显式重置代码）；强制档修不完走拒绝回执→后续重试 attempt 维持 pro 至段终（错误未清零仍在窗口内）。**不建迭代级切档、不建段内降档机制。**

**正身＝窄修派发**：lint 场景（样式 #296＋基座强制档 #425；生成轨与 fork 片）的修轮派发改窄修文案——工作区已有产出为准、收口判据已过、仅消除清单内违规、不得重构/重写已完成产出。能力面真失败的重试派发不动（兜底语义不变）。

## Considered Options

- **迭代级动态档位（落点 A）**——拒绝：attempt 内迭代循环在外部库（agentscope）内核，平台唯一缝＝streamLayer Model 装饰器；「attempt 内错误已解」信号通道不存在、需先建；改动横跨 base/business 两分区（装饰器＋RuntimeContext 状态袋＋中间件 SPI＋双档下发＋观测语义重构＋verify 子智能体连带）；窄修派发后修轮 attempt 只剩几次迭代，边际收益趋零；26-32% 快修形态在 attempt 级钉死下已实证出现。
- **lint 修轮不升档、flash 自修（落点 B2）**——拒绝：违背「错误处理中＝strong」裁决语义；flash 产出违规本说明该面不可靠，修不动→强制档拒绝→多耗 attempt 反升成本；且须让路由区分重试成因——纯计数是路由的简单性资产。
- **维持现状软句（「不要重做已对的工作」）**——拒绝：软句无约束力，复演实证 92% 级重做。

## Consequences

- 路由零改、观测零改：attempts[].modelId 保持每 attempt 单真值；窄比例验收走 attempts[].overheadMs.iterations × modelId，深查走 met_usage_events 逐调用模型账。
- 非目标不动：lintFixRoundUsed 一轮上限、违规清单截断 20 条、#425 强制档拒绝回路、#353 段级回滚重跑升档。
- 验收锚：lint 族修轮 attempt 迭代 ≤ 首试 50%、全场无 ≥90% 段；修完即段终；能力面兜底与尝试次数机制不变。
- 与 #471 正交叠加：#471 消灭可避免的升档（诱因面），本裁决控制升档发生时的成本（窗口面）。
