# 生成道改形：全局 FIFO＋错峰准入，关停中断口径与秒败免预算

#477 定档（2026-11-12，11-12 生产事故续票；承 ADR-0042 分池、#359 停止面、#221 尝试环）。现状事实三件：① **发版即满车道**——发版重启后自愈续跑的中断生成 run 15 秒内齐发占死生成道（eu-1 实测容量 2-3 并发生成、6-8 个 ws 容器近极限，而宽度缺省 8），此后新建项目的生成全在排队，「第一个建项目的人必中招」；② **关停风暴烧账**——SIGTERM 宽限窗内 `AgentShuttingDownException` 被尝试环当普通可重试失败：升档秒败（llmMs=0）×3 烧满转终态（本应「中断可续跑」）、排队轮继续被拉起各烧一轮、6m50s 进度报废；③ **删除不取消在飞任务**——DELETE 级联删库行＋容器后进程内任务存活，对着 No such container 反复自救 ~8 分钟（僵尸烧 lane＋烧 token）。定案：

**生成道＝全局 FIFO＋固定 worker 池＋错峰准入**：宽度（worker 数）＝跨项目并发产出轨上界不变（`app.agentscope.generation-stripes`）；不再 sessionId 哈希落位——哈希碰撞会把新项目生成任务排在无关小时任务后等数小时（#475 评审预言的「事故在池内复刻」，11-12 发版窗口成真），FIFO 保证「有空闲 worker 即起跑」；同会话串行不变量由取件规则保住（会话在途执行中其排队任务保序留队——CodingRunTrack 单轨之外的第二道进程内保险）。**错峰准入**：相邻生成任务起跑至少隔 `app.agentscope.generation-admission-interval`（缺省 10s、0＝关）——洪水齐发是「发版即满车道」的形态；车道空闲（间隔窗已过）即取即跑，稳态单任务零新增延迟。`Future cancel(true)` 停止语义不变（中断在途执行线程，#359/#477 删除级联同通道）。

**关停中断口径**：优雅关停宽限窗内的一切编码 run 收场按「中断可续跑」处置——`AgentShuttingDownException` 一律不可重试（不烧尝试预算、不升档、不触发下一轮尝试、不发终态事件、不触发段回滚），尝试环掷 `RunShutdownException` 旁路、片保持待跑（重启后「继续生成」断点续跑）；执行器关停排空（宽限窗内排队任务不出队执行——拉起只会秒败烧账）。

**通道级秒败免预算＋重派上限**：`AgentTurnFailure` 且 `llmMs=0`（未发生真实模型调用——连接/凭证级通道错误）不消耗正常尝试预算，走独立免预算重试账（封顶 `app.generation.channel-instant-retry-max`＝3、指数退避 2s 起封顶 30s、同尝试序干净重发不升档）；额度尽回落正常预算防无限循环。整场 run 全尝试皆通道级秒败（逐尝试 `channelInstant` 标记，非裸 llmMs==0——前段/环境失败零桶不算）即「通道全死」：生成轨停派后续片、修正轨排队残局并入终态账（恢复出口一次带走，意见零丢失）——「转终态→重派→秒败」循环结构性出局；有真实模型工作的失败不受影响（#429 失败续派口径不变）。删除项目先经 #359 停止面级联取消在飞任务。

## Considered Options

- **生成道保留 stripe＋仅加错峰**（ADR-0042 原案微调）——拒绝：错峰只治齐发形态，治不了池内哈希碰撞饿死（新项目生成任务落在被小时任务占死的 stripe 后等数小时——发版窗口 7/8 命中率）；ADR-0042 曾以「手写调度器复杂度」拒绝全局 FIFO，11-12 发版窗口的碰撞事实把「产出轨并发数小、差异不抵复杂度」前提推翻。
- **按「续跑/新跑」分优先级准入**——拒绝：平台层无此区分（重启洪水是 N 个用户各自的续跑，新项目 run 与之同形）；FIFO 即公平基线，容量正身归宽度配置（#478 线定档）。
- **关停中断发 run-failed(interrupted) 终态事件**——拒绝：进程正死，SSE 与落库都在跟关停赛跑；「中断可续跑」的正身是片保持待跑（轨道表事实），事件面无读者。对偶用户停止（#359）发 stopped 事件是因为进程活着、前端要收口呈现。
- **免预算重试不封顶**——拒绝：通道长期故障（key 失效级）下成无限循环；封顶回落正常预算，终态兜底口径不变。

## Consequences

- 交互车道 stripe 设计不动（碰撞代价＝秒级排队，无害；`stripeIndex` 测试缝保留）；生成道 `generationQueuedCount`、入队/出队日志契约不变（#475 验收锚续用）。
- 错峰缺省 10s：稳态零成本（车道空闲即取即跑），发版洪水 7 场≈70s 拉开起跑；单机容量定档（宽度调低）后错峰是第二道护栏，非替代。
- `attempts[].channelInstant` 进失败面（平台分析口径，前端不渲染）；免预算重试不进逐尝试账（WARN 日志留痕——事实为空，无观察可携）。
- 关停排空覆盖交互车道（宽限窗内排队轮同样不出队——在飞轮只死一次，悬空机制〔ADR-0032〕兜住）。
- 删除级联取消后，僵尸任务按停止收场可能对已删项目发一条 run-failed(stopped)／落一行对话史（quietly）——孤儿行无害（项目行已删、无读者），换取 8 分钟僵尸 lane/token 烧损消除。
- 验收锚：关停中断一次尝试即收场（不重试不升档不终态）；免预算秒败后真实调用恢复即收口（重试现场不前移）；通道全死终态后后续片/排队意见不再入场；删除后停止面即时置位；洪水起跑按间隔错峰（回归测试钉死）。
