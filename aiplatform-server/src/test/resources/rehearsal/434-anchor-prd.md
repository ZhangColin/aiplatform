# 背词记忆管家 — 产品需求文档（PRD）

## 一、需求背景

小朋友学习英语单词时，传统的背诵方式缺少科学的复习节奏，学过容易忘；家长想督促孩子但看不到学习细节。本系统希望提供一个**以记忆曲线为核心**的背单词工具：孩子通过**手机拍照识别**或**打字输入**录入新单词，系统按**经典艾宾浩斯曲线**自动安排复习测试，孩子随时学习、家长随时掌握学习与复习情况。

核心诉求：
- 低门槛录入：孩子可以拍课本上的单词（OCR自动识别），也可以直接打字输入
- 科学复习：按经典记忆曲线安排测试节奏，巩固记忆
- 双端口：孩子端负责学与测，家长端负责监控与督促

## 二、目标用户

**各年龄段通用**——幼儿园到初高中学生均可用：

| 用户角色 | 描述 | 核心诉求 |
|---------|------|---------|
| 孩子（学习者） | 3-18岁的学生，各年龄段通用 | 轻松录入新词、按节奏复习、多题型测试巩固记忆 |
| 家长（监控者） | 孩子的父母或监护人 | 实时掌握孩子学习/复习情况，了解薄弱点，及时督促 |

界面设计兼顾低龄（大字、图形化、拼音辅助可选）与学龄（正常文字密度）的可用性。

## 三、核心场景

1. **录入新词**：孩子通过手机摄像头对准书上的单词拍照，OCR自动识别出单词文本；或直接打字输入单词。系统自动补全中文释义与发音，可手动修正。
2. **学习与测试**：按记忆曲线安排复习提醒，孩子在提醒时进入测试。测试题型按单词熟练度自动切换：
   - **选择题**：给出中文选英文 / 给出英文选中文
   - **拼写题**：看中文写出英文
   - **听力题**：听标准发音选对应单词
   - **综合**：根据熟练度动态切换题型
3. **家长监控**：家长登录家长端，查看孩子的学习进度、单词掌握情况、错词分析、学习时长与活跃度；孩子该复习没复习时收到提醒推送。
4. **单词来源多元**：孩子录课本生词、家长指定单词列表、孩子自主发现感兴趣的词——多种来源都支持。

## 四、范围边界

**本系统包含：**

- 孩子端：登录、录词（拍照OCR/打字）、学词、记忆曲线测试（四类题型）、单词本管理
- 家长端：登录、学习进度查看、掌握情况查看、错词分析、活跃度/时长统计、复习提醒推送
- 单词信息：标准发音（真人发音）、中文释义、可手动修正
- 账号体系：孩子/家长各自登录（简单账号体系，支持单孩子绑定单家长）

**本系统不包含（第一期）：**

- 多人/多孩子管理（一个家长账号绑定多个孩子）——后续可扩展
- 老师参与/班级协作——后续可扩展
- 社交/排行/激励游戏化模块——后续可考虑
- 英语内容生产（如教材同步词库导入）——单词由用户录入，系统不预置大词库

## 五、关键约束

1. **OCR识别**：拍照识别需依赖OCR能力，识别结果可能不精准，需提供手动修正入口。
2. **释义与发音数据源**：系统需接入词典与发音数据源，自动补全单词的释义和标准发音。
3. **记忆曲线节奏**：固定采用经典艾宾浩斯间隔——约5分钟/30分钟/12小时/1天/2天/4天/7天/15天。
4. **测试题型切换**：系统根据单词的熟练度（记忆状态）自动决定当次测试题型；所有题型最终服务于记忆巩固。
5. **发音播放**：听力题型必须有标准发音播放能力。
6. **系统形态**：本系统为手机端优先的网页应用（孩子用手机操作），家长端同一系统内独立视图。

## 六、功能清单

### 孩子端

**P1 用户注册/登录**
- 孩子注册并登录自己的账号
- 验收：孩子能注册账号并登录；登录态保持

**P2 录入新单词**
- 支持手机拍照识别单词（OCR自动识别文本）
- 支持手动打字输入单词
- 系统自动补全：中文释义、标准发音
- 用户可手动修正释义
- 验收：拍课本上的单词能识别出文本；手动输入能录入；录完有发音可播、有释义展示

**P3 单词本管理**
- 展示已录入的所有单词，按学习状态分组（待学习/学习中/已掌握/易错词）
- 支持删除单词
- 验收：单词列表可按状态筛选查看；能删除单词

**P4 学单词**
- 查看单词卡片：单词、发音、中文释义
- 播放标准发音
- 验收：点击单词卡片可听发音、看释义

**P5 记忆曲线测试**
- 系统按艾宾浩斯间隔（约5分钟/30分钟/12小时/1天/2天/4天/7天/15天）安排复习提醒
- 进入测试后按熟练度切换题型：
  - 选择题：给出中文选英文 / 给出英文选中文
  - 拼写题：看中文写英文
  - 听力题：听发音选单词
- 答对推进记忆等级、答错回退
- 测试完成后展示本轮结果（对/错、进步情况）
- 验收：到期单词有提醒；测试题型随熟练度变化；答对/答错有记忆等级变化反馈；每轮测试有结果页

**P6 学习提醒**
- 到期该复习的单词向孩子提醒
- 验收：到了复习节点，孩子端能收到提醒并可一键进入测试

### 家长端

**P7 家长注册/登录**
- 家长注册并登录自己的账号，绑定孩子账号
- 验收：家长能注册登录并绑定孩子

**P8 学习进度监控**
- 查看今日学了几个词、复习了几个词
- 查看累计已学/已掌握/进行中的单词数
- 验收：家长端能看到孩子当天与累计的学习/复习数据

**P9 掌握情况查看**
- 按单词/批次查看每个单词的熟练度状态
- 验收：家长能看到每个单词的掌握状态（未学/学习中/已掌握）

**P10 错词分析**
- 展示高频出错的单词，识别孩子"总是记不住"的词
- 验收：家长端能看到错词列表及错误次数

**P11 学习时长/活跃度统计**
- 查看孩子每天学习时长、最近学习日期、连续学习天数
- 验收：家长能看到每日学习时长与活跃趋势

**P12 复习提醒推送**
- 孩子到期该复习而未复习时，向家长发送提醒
- 验收：孩子逾期未复习，家长端有提醒提示

## 七、验收与待确认

### 阻碍核心流程
暂无——核心流程（录入→记忆曲线测试→家长监控）已全部确认。

### 次要未知
1. **【功能与边界】孩子端拍照OCR的识别精度与出错兜底**：OCR对印刷体识别准确率较高，但对手写/花体可能出错。假设：系统提供识别失败时的手动输入兜底，识别结果可修正，不作过度承诺。
2. **【数据与约束】发音数据源的来源**：假设使用在线标准发音接口（如TTS或预录音频库）。具体音源在选择技术方案时确定。
3. **【验收】家长端绑定孩子的方式**：假设通过邀请码/验证码绑定，具体方式在实现时确定。
4. **【功能与边界】记忆曲线的提醒渠道**：假设系统内提醒（非短信/推送通知，因网页应用环境限制）。如用户需要外部推送需另行确认。
