# 图片管道公共底座：工作区正本、正身入 git、零对话图片部件、支付门下载与执行体侧转存

设计能力线图片管道裁决（2026-10-03，#276，承 ADR-0023 交付物包、ADR-0025 过程形态、ADR-0026 出图档位；现状事实＝消息模型纯文本五种 part 在产、附件唯一类型 annotation 有壳无管、服务端零上传端点零 multipart 配置、点看按 NUL 嗅探拒非文本（PRJ_023）、唯一下载先例＝用户/后台面三个 tar.gz 端点、平台无工作区文件直读路由——一切经 docker exec）定案：**存储正本＝工作区**——图片（生成稿、上传物料、PNG 衍生件）一律落工作区容器卷的产物/物料/导出物目录（WorkspaceLayout 单一事实扩目录），平台经既有 docker exec 通道读写，零平台侧文件库、零对象存储起步（腾讯 OSS 等外移备案：触发器＝多项目图片体量成封存/备份负担或外链加速需求成立）；封存整卷打包只排缓存目录＝图天然随卷保全。**版本化规则＝正身入 git、衍生与输入不入**（刀＝可再生性）：不可再生的图（图片模型位图稿，含候选各代）入版本流 git——代价如实：每代 3 稿×N 代、一设计物几十 MB 量级，打磨期接受；可再生衍生（平面 HTML 稿的 PNG——HTML 源入 git、SVG→PNG 导出件）与输入（上传物料图）gitignore 不入；「查看当时」对不入 git 的图如实降级（只见源件/占位）。**对话区/SSE 零图片部件**：part 封闭集零扩展（part-attachment 契约位既留、继续不开；备案触发器＝真出现「对话中必须指图说话」场景，如改稿意见对着图圈点）；图片本体一律走平台文件服务路由（raw content-type、鉴权与用户隔离对偶既有口径、非信封先例＝源码包端点）；对话史落库形态零改动。**点看与下载**：文件区点看从纯文本扩图片 inline 大图（raw 路由，点看判定对图片放行 NUL 拒收）；单文件下载＝**通用**（文件区一切文件、Content-Disposition、不按类型开洞）＋**支付门**——未付费不可下载，判定＝项目曾有已支付/已归档订单即开放（迭代期间已购保持可取），仅盖下载面（单文件＋源码包＋设计资产包；点看/预览/设计稿 tab 自由——平台上随便体验、带走才付费，与「止于支付完成」同构）；现状 source-package 端点补门对齐（无门→有门，打磨期自用零存量影响、上线前复核）；后台面是运营侧、不受用户支付门约束。**转存＝执行体侧落盘**：出图工具件在容器内下载供应商 URL（24h 时效）写盘产物目录，URL 只作中转、不入库不透出前端；下载失败走 ADR-0026 技术失败有限重试口径、不产新概念。**上传＝管道做、消费按现有能力**：新建 multipart 端点落物料目录（服务端零上传基建是纯增量）；单文件 ≤10MB、格式 png/jpg/webp/gif/svg、超限如实报错不静默压缩；附件 attachmentType 扩 image 值（载荷＝工作区路径引用、不带字节；前端既有壳——Composer 文件选择记名即弃＋完整附件组件族零引用——补真断链而非发明新交互）；v1 消费者＝代码出图把图片物料嵌进 HTML 稿（img 引用文件路径、chromium 渲染成稿）＋物料归档；img2img 工具件（触发器＝参考图直接改稿需求成立）与多模态视觉输入（触发器＝#277 提炼或改稿真需要看图）备案。词汇：不立「参考图」新词——就是图片物料。**设计资产包导出**：下单冻结时选件式打包入导出物目录（tar 流内核复用源码包先例、排除式改选件式：选定稿自包含 HTML＋DESIGN.md 式规范＋衍生资产，ADR-0023 口径）；已支付后可下载（同支付门）；用户面新端点对偶 source-package。**位图出口触发点**：平面类出稿即渲 PNG（稿卡大图用 PNG、HTML 源同存——stitch 双形态同构，即「平面类图一次到达」之「图」）；界面类 v1 零截图（稿卡＝iframe live 渐进呈现正身；快照缩略图备案：触发器＝阵列 iframe 数量真成性能/滚动问题）；SVG 原生物件导出时走 resvg/sharp 特价路径产 PNG 衍生；多分辨率衍生（2x/4x）备案（触发器＝交付质量要求）。

## Considered Options

- **平台侧文件库/对象存储起步**——拒绝：产物之家已是工作区（文件区四分目录、版本流 git、封存整卷全在工作区语义内），平台侧开第二正本纯增机制；OSS 备案带触发器。
- **图片全量入 git / 全量不入 git**——拒绝（细分定档）：以可再生性为刀——正身入、衍生与输入不入；全量入吃无谓膨胀（可再生 PNG 重复版本化），全量不入丢不可再生位图稿的版本语义（「查看当时」看不到定稿稿）。
- **对话区图片部件（启用 part-attachment / 新增 part-image）**——拒绝：ADR-0025 已定设计稿到达不入对话流、解说播报、收尾卡带稿清单；上传回显走发送框附件区；图片呈现之家＝设计稿 tab 与文件区；对话史零改动。
- **单文件下载仅图片可用**——拒绝（用户改判通用）：同一机制零新概念，「文件能下载」是均匀预期、不按类型开洞；代价是支付门统一盖下载面（用户拍板：未付费不可下载——平台随便体验、带走才付费）。
- **平台侧转存服务（backend 拦截 URL 代下载）**——拒绝：出图工具件本就跑在容器内（egress allowall 先例 ADR-0019）、写盘是执行体既有能力；平台侧转存要多一条 backend↔容器的文件回流路，纯增机制。
- **上传整体备案（等 img2img/视觉输入落地再做）**——拒绝：设计线第一步真实交互缺口（参考图是高频首诉）且 v1 有真消费者（HTML 嵌图成稿）非死 UI；管道一次做齐，后续只加工具不加管道。
- **界面类稿卡快照缩略图**——拒绝：渐进呈现本身可感知（iframe live 渲染是硬要求正身），缩略图是无需求投机；备案带性能触发器。

## Consequences

- CONTEXT.md 随改：新增「物料」词条（用户上传的文件资料、图片为一形态、与外部资料对偶——上传 vs 抓取）；其余零新词（设计稿「多格式导出」、交付物包「图部件」、单价表「按张」既有词条已盖）。
- #272「图部件入交付物包」备案触发器两条件（#275＋#276）全落地：图部件正式入交付物包语义，词条已含、零改。
- #278 原型票拿到数据源承诺：设计稿 tab（范式注册表新项）呈现＝稿卡从平台文件服务路由取件，稿到达信号走既有事件、SSE 零扩展；稿 HTML 伺服通道同源本口径。
- #281 后台运营面：设计资产包随单可见、后台项目文件下载不受用户支付门约束（运营侧）。
- source-package 端点补门是现有行为变更（无门→有门）：打磨期自用零影响，对外上线前复核。
- 首页入口带图上传（create-hero 附件静默丢弃现状）备案，视角归 #280 入口票。
- 点看 raw 路由的图片大小上界（≤25MB 量级）与物料/产物目录具名是实现自由度，归实施。
