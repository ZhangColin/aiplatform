## 四、观察到的缺陷（新应用）

1. `GET /favicon.ico` 404 → 每个页面控制台报一条 `Failed to load resource: 404`（截图全程仅此一类控制台错误；无 pageerror、无 HTTP 5xx）。旧应用有 `icon.svg`（200），这点新应用不如旧应用。
2. `GET /api/health` 404（旧应用有）。非 PRD 要求，运维面小缺口。
3. 看板「已关闭」列头写死「最近 8 条」，实际仅 7 条（CLOSED_VISIBLE 常量与数据不符），纯文案瑕疵。
4. 「超期 XXh」徽章显示的是当前状态总时长（ageHours），不是超出 48 小时的部分（如 66h 总时长显示「超期 66h」而非「超 18h」），文案有歧义，功能本身正确。
5. 业务校验失败返回 HTTP 200＋`{ok:false,reason}`（实现说明已声明的设计选择），非 REST 惯例，不算功能缺陷。

未发现：空白页、报错覆盖层、布局破碎、乱码（截图中中文全部正常）、HTTP 500。
