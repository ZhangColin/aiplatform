# 技能线：智能体运营配置落库（修订 ADR-0006 边界）＋技能快照安装与动态装配

技能线 grill（2026-09-22，依据 docs/research/2026-09-22-skill-line-mechanism-and-benchmark.md）要后台安装/启停/指派技能、可维护提示词——与 ADR-0006「智能体配置不落库」（AgentProfile 枚举正本）正面相撞。决策：**身份与配置分治**——智能体身份（有哪些智能体、职能、寻址键）仍不落库，AgentProfile 枚举仍是正本；运营配置（systemPrompt、modelId、技能指派、增强工具开关）落库、后台可维护，变更留痕 append-only（操作者＋旧值快照），回滚＝写回旧值。技能**快照安装**：装时从外部技能仓库（git URL，仓库级导入可勾选排除）固化进平台技能库（base 新 skills 模块，对齐 knowledge 先例），版本＝装时 commit 留痕，更新＝后台定期只读检查远端 HEAD 标「有新版」、显式点更新。装配生效：技能装配返回**动态查库的 repository 视图**（非装配时固化），DynamicSkillMiddleware 每轮重建——指派/启停变更下一轮自然生效、进行中 run 不定格，工厂缓存键不改；prompt 变更因缓存键已含 sysPrompt 自然新实例。分层纪律入 CONTEXT.md 技能词条（内建工作协议只载身份/编排/约束/技能指路，方法论一律住技能层），其执行（EXECUTOR 厚 prompt 方法论迁出）单开瘦身票，本线受兼容约束三条保障不堵演进：来源枚举含内置、prompt 落库可维护、指派机制通用——瘦身落地＝改 prompt＋建技能＋指派三个后台动作。

## Considered Options

- **GitSkillRepository 订阅式直连**（每次读检查远端 HEAD 自动 pull）——拒绝：远端删改直接漂进平台智能体，后台清单非事实，与「安装＝固化版本、后台可控」语义相抵触；其 HEAD 检查逻辑复用为更新检查。
- **技能集进工厂缓存键**——拒绝：装配动态 repository 后复用实例内容亦动态，改键徒增实例 churn。
- **子智能体全量继承执行体技能面**——拒绝：superpowers SUBAGENT-STOP 实践佐证子智能体技能面要收窄（审查者不喂成半个实现者）；子智能体独立配置（职能声明扩展技能字段）。
- **工具参数通用配置机制**——备案：每个工具参数 schema 千差万别，通用机制属投机性复杂度；触发器＝第一个真实需要后台可配的工具出现，带具体 schema 一起做。工具面现在只做可观测＋增强型窄幅开关（WebSearch/FetchUrl 可关、骨架工具锁死）。
- **SkillSecurityScanner 现在接入**——备案：现在靠后台管理员人工审（injection 面＋方法论重叠面，对齐后台写操作留痕信任模型）；触发器＝安装源放开到非受信来源。
- **市场（skills.sh 等）直连安装**——备案：git URL 单源先吃全生态（SKILL.md 同规范），市场索引接入待真实需求。
- **classify/naming 一次性提示词进后台**——拒绝：入口车道判定的实现细节，非智能体身份面。
- **「自制」来源（工作区 .platform/skills/）单独成途**——拒绝：并入自产线（技能自学习闭环票）一并钉，词条来源收「内置/安装/自产」三途。

## Consequences

- ADR-0006 半保留（身份枚举）半修订（运营配置落库）——未来读者以本 ADR 为准理解「不落库」的现行边界。
- EXECUTOR 现行厚 prompt 与方法论技能的双头风险**已知并接受**：机制不设硬禁，审核指引软性暂缓方法论包指派，瘦身票收口（解除指引）。
- 安装内容面收知识/规范（a）＋脚本（c，开放面＝有 shell 的槽位；主智能体 ProjectReadOnly 禁 shell，结构上 a-only）；工具组绑定（b）属平台自制技能线，结构位预留。
- 用户面完全隐式（对齐知识命中语义），技能加载使用不作用户面概念呈现。
