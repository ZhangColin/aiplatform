# 计量峰谷：单价表时段带＋独立时段规则表，节假日 v1 近似

计量单价表演化裁决（2026-11-13，#470 用户裁决；承 #160 成本运营、#165 单价写口唯一化）。现状事实：DeepSeek 官方定价页 2026-08-16 起分 peak/off-peak 时段价（谷＝峰半价；peak＝工作日 01:00–04:00、06:00–10:00 UTC，法定节假日全天谷），而单价表无时段维度——种子脚本按 peak 上限种入并明文备案「精确到时段的换算是单价表演化，现在不预设」（backoffice-price-seed.sh）。11-11 烧钱事件对账实测：全按峰值计金额高估 ≈21%（pro 仅 +7%、flash +74%——晚间大波全落谷段），峰值口径只能作过渡。定案：

**独立时段规则表＋单价表加时段带列**：时段规则（通道 × 生效区间 × 星期口径 × UTC 窗口行）独立建表、与单价表同样关行开新行生命周期——时段与单价是两个独立变化节奏（供应商调窗口≠调价，分表各自生效）；单价表加「时段带」列（峰/谷，NULL＝不区分时段——无峰谷通道与按张行存量语义零变动、迁移向后兼容），匹配键、唯一约束（provider, model, token_kind, band, effective_from）与 METER_008 重叠校验同步扩展。

**读时归段选价**：成本聚合换算匹配（PRICE_MATCH 单点）扩展——事件 ts → 该通道 ts 时点生效的时段规则 → 归带（峰/谷）→ 选对应带单价行；通道无生效规则行＝不看时段。不落存金额列：改价/补价时引入漂移风险，与「历史成本不漂移」相抵，读时折算已是现状。

**节假日 v1 周一至周五近似**：周六日全天谷判对；法定节假日（约 30 天/年）当工作日计峰→高估、调休上班周末（约 5–8 天/年）当周末计谷→低估，部分对冲、净偏差为二阶量（对照平台计量 1.6% 正常泄漏）；schema 预留日期覆写行（通道 × 日期 × 全天带），将来上年度中国节假日日历免迁移；升级触发＝节假日密集月份对账缺口明显超出泄漏容差。调休日 DeepSeek 实际口径为已知未知（价目页核对时一并确认）。

**初始化顺序结构先行（S1）**：先落结构（V62＋引擎归段＋时段规则写口）再种真值行，不落峰值过渡行——「峰值口径」标注、回溯纠正周期、两次种子全免；若结构实现搁浅超一两周，降级路径为现有脚本按上界种入（S2）、结构落地后回溯关行换真值行（改价生效起点可回溯，机制已备）。

## Considered Options

- **单价表每行内嵌时段窗口**——拒绝：每模型六行重复同一窗口定义；供应商调时段不调价时要改六行；两个变化节奏耦合在一行内。
- **代码写死 DeepSeek 峰谷规则**——拒绝：时段是供应商侧数据、要进后台维护面，且多通道并存（volcengine 另票）各有口径，写死无法运营。
- **峰谷塞进「档位」维度**——拒绝：档位已含 token 档位（未命中/命中/输出）与按张；峰谷横切所有 token 档位，是正交维度，不进档位枚举。
- **v1 即维护年度中国节假日日历**——拒绝：每年维护成本＋数据源负担，净偏差二阶；覆写行预留使升级免迁移，不必预付。
- **S2 止血先行（先峰值行后回溯换值）为默认**——拒绝：11-11 对账已手工完成、无急迫的上界金额消费者；中间态标注（admin-web 要为注定拆除的过渡态做功能）与纠正周期是纯开销。仅作结构搁浅时的降级路径保留。
- **落存金额列**——拒绝：与「历史成本不漂移」的关行开新行机制相抵触；读时折算已是现状架构。

## Consequences

- 迁移 V62：单价表加 band 列＋扩展唯一约束、新时段规则表；成本聚合 PRICE_MATCH（UsageEventAggregationsImpl）为引擎唯一改动面（SQL 内归段：星期＋UTC 窗口判定，窗口跨午夜表示法在实现票定）。
- 时段规则写口对称 #165 模式：开/改/停三个机机签名端点（五头 HMAC、admin BFF 持密钥签名、操作者留痕），初始规则经幂等签名脚本种入。
- 种子脚本重写 deepseek 行：CNY 每 token 真值 12 行（峰/谷 × 未命中/命中/输出 × 两模型）、生效起点 2026-01-01 改 2026-11-11；volcengine 行不动（另票补入）。落库门禁：DeepSeek 后台价格页人工核对＋模型名字串与 met_usage_events.model 一致性核对、种子前查 deepseek 通道 min(ts) 证实 11-11 前无事件。
- 后台用量面 v1：金额折算（读时）、按通道过滤、默认按金额排序、峰/谷拆分列（GROUP BY band 顺手维度）、缺价不伪装 0（口径已有）。
- admin 侧（semgravio-admin BFF＋admin-web 表单与展示）按惯例后发对接票、收口互链。
- CONTEXT.md 随本裁决更新：单价表词条扩「通道/时段带」维度、新增「时段规则」「缺价」词条。
