# 生成过程呈现：工具动作流＋收尾卡＋预览跟随

分钟级生成窗口的用户等待体验定案（承 从零重设总索引 #573，决议见 #578「生成过程展示」，2026-11-21/22 两轮裁决）。实证依据（v0-run1 逐轮日志，276 轮）：裸内核不产过程解说（模型文本 38 次全部出现在自认完成的收尾轮，工具轮基本零文本）；假完成毒性（第 86 轮即宣告完成，被「催促继续」顶回再干 190 轮——直播即「已完成→又干 15 分钟」的无意义震荡）；末次文本实形佳（功能清单＋验证数字＋运行口径＝天然收尾解说）。本文取代 ADR-0010 的呈现面定案（ADR-0010 保留为历史记录并改记）。

## 决策

**过程流＝工具动作流**：活性行＝唯一实时状态行（bash＝命令原值剥壳定宽截断、write_file＝「编写【文件名】」）＋「已生成 mm:ss」时钟（时间戳单源＝生成起点事件时间戳、前端每秒渲染、终态定格）。轮次计数不呈现。

**模型文本一律不直播**；生成自然终止后取**末次文本**落收尾卡「内核自述」字段（markdown 渲染）；中途 idle 文本不呈现——「完成」宣告权＝终态而非模型嘴说。

**预览窗三段**：占位态（一句话＋时钟信号）→**探活通过即转可用**（「跑着」判据的可视化时刻）→**跟随模式**（默认开＋「固定」开关）：write_file 路径纯前端映射路由（剥分组段）、**仅路由变化才导航**（同页反复重写不跳，热更白嫖）；组件／库文件不切页；迭代轮改哪页切哪页；降级自担（编译中白屏、非 dev 形态无热更），不加机制兜。跟随＝有意义的变化，不算震荡。

**落库三件套原样承接**：①生成过程明细（活性行／动作流水）不落库；②SSE 断线补发窗口承担刷新短回放（恢复活性行现值）；③界面侧轻会话消息（用户发言／澄清问答／收尾卡）落库＋REST 水合——「刷新不丢」由界面消息落库承担。生成中刷新＝线程恢复＋生成卡（进行中态＋时钟＋补发窗口内活性行现值），过程明细历史不回放。收口定格留驻、活性行随收尾卡入流沉没保留。

**收尾卡＝一次生成一张**（首建／修改同粒度）。五字段：**用时**（后端实测口径）／**判据结果**（build ✓＋探活 ✓——机器面唯一硬判据的可视化）／**变更清单**（git 跑前快照 diff，零新增数据源：迭代轮＝文件级 ±行数清单＋单文件只读 diff 视图；首建＝目录级汇总＋可展开文件级，百文件不裸列）／**内核自述**（末次文本）／**预览入口**。

**定名「生成」**：一次生成＝生成内核一次执行到自然终止。用户面话术全链「生成中…」「生成完成」「在途生成不打断」。

**失败呈现**：失败留痕（红行＝label＋错误首行）＋失败终态明确展示＋重跑即恢复（新失败语义，ADR-0056）；失败留账观测面保留口径、随新失败形态重建。

## 出局清单（呈现面）

计划区两级（切片级＋步骤级）｜update_plan 步骤清单部件｜切片级多收尾卡｜「正在创建首页」渐进占位（绑定切片起服节奏的旧形）｜轮次计数呈现｜文件树面板｜流式解说直播｜平台通知消费（完成＝线程内收尾卡所见；SSE 通知通道保留、零新发布点；离线召回＝短信／推送级需求的重启条件）。

## Considered Options

- **流式解说直播**——否决：内核不产解说；假完成毒性实测（38 次文本 37 次假宣告）；重启条件：实证显示长窗口人话不足→「解说请求」进提示词（走准入标准，基线不动）。
- **文件树面板／轮次计数**——否决：新机制＋新轮询；信息已被活性行承载。重启条件：实证显示工具动作流信息不足。
- **平台通知作为第二消费面**——否决（用户裁决）：页面开着自然看到，无需通知；重启条件＝给不在电脑前的用户发短信／推送、多项目并发跨项目完成信号、后台运营推送面。
- **步骤清单部件（part-plan）**——出局：工具不在内核四件内；计划＝切片机遗产。

## Consequences

- 智能体事件部件模型收窄重建（保留：工具动作部件三面语义＝直播播报／成功不留史／失败留痕；叙事段守卫；脱轨信号部件。出局：步骤清单部件；思考／代码补丁／步骤分组不呈现原样）。
- 对话史以界面侧轻会话形态重建（ADR-0056）；SSE 原样保留（ADR-0018）。
- 施工面：跟随模式、收尾卡五字段、diff 视图、占位态、时钟；事件映射层收窄。见施工交接清单。
- 新词条随本文落 CONTEXT.md：生成（重写）、一次生成、内核自述、预览跟随；「对话区」「对话史」「平台通知」「智能体事件」各词条改记。
