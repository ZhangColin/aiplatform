已确认的主路径
无需注册即可开始需求问答，逐步形成 PRD。
确认 PRD 后先生成 1 个 Demo，根据用户反馈迭代。
用户确认 Demo 后核对范围与报价，完成合同签署。
合同要求的签署完成且开工付款条件满足后，进入正式生产。

素材
assets 目录包含从现有材料提取的 Logo 和网站业务流程 SVG、PNG。
白色透明 Logo 应在深色背景查看；素材细节以目录内说明为准。
流程图用于说明业务顺序，不是 UI 设计稿。

设计范围
极简首页和连续项目工作区，覆盖桌面与手机。
客户前台以需求分析、Demo 体验、签约付款为三个主阶段。
生产环节首版仅提供状态和下一步，不扩展为复杂研发管理系统。

需后续确定
访客保存期限、Demo 收费和迭代额度、正式报价、合同服务与主体、付款渠道及开工款规则。
这些项目不影响整体界面结构设计；不可将占位信息当作正式商业承诺。

原始材料未修改。ZIP 不包含内部制作脚本、排版检查图片、融资材料原件或个人履历材料。
