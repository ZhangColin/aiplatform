# 基座预置扩张与 AI 复用纪律

生成「快与美」的基座面定档（承 wayfinder 地图 #510「基座模板扩张」子域、决议正本＝#517；用户取向重申＝「像开发团队一样预置好常用功能框架」——与 ADR-0035 拒绝登录页收编时的同源表述，本轮把「框架」外延从横切健壮能力扩到高频通用模式）。两个核心风险（老板原话）正面作答：**预置致所有系统呈现单一化**；**AI 不用现成的自己另写一套、或对预置件大改比新做一个还耗时**。策略以 #511/#512 竞品取证为凭；基座现状实锚（#517 只读侦察）：模板正本＝classpath `docker/workspace/baseline/`（33 文件 Next.js 工程、镜像 tag 单源 `DEV_IMAGE`、构建期 `pnpm test` 狗粮门）、首批四件套已实装（`lib/robust`＋`components/robust`）、**无任何布局/导航/主题文件**（现状即目标态）、栈规则集＝run 派发时按健壮件在场探针拼入工作区 AGENTS.md 的常量节（随基座 tag 换版、存量不拼）、基座 lint＝`RobustKitLintAppService` 容器内 grep 真跑两档（强制档违规喂修轮→用尽按失败→段级回滚重跑间接升档，11-12 复演 7 升档全 lint 族实证；预置档 #471 已收窄不触发修轮；无运营开关）。

## 决策

**预置取向与判据扩档**：预置扩张走「常用功能框架」取向，不走「平台业务能力」取向——功能域业务件（支付/通知等）仍永留执行体（ADR-0035 边界不变）。判据两档并存：健壮件判据（每应用都要写、与具体功能无关）之外新增**模式件判据＝跨项目高频出现的通用 UI 模式**。

**首批模式件两件＋承载层**：表单＋校验＋提交态、列表＋筛选＋分页（竞品与常识双高）。承载＝baseline 内成件（`components/patterns/` 命名随实施定——import 即用、未用被 tree-shaking 自然消、自带行为契约测试吃构建期狗粮门、随镜像 tag 换版）＋栈规则集补用法节（件在哪、怎么用、纪律句）。其余候选（图表卡/设置页壳/上传/搜索…）挂「盘点后定」——盘点＝现网已生成应用的模式占比（工作区卷检查通道现成）、进实施切片、与 ADR-0050 对照轮同班次顺路；首批不闭门造长单。

**模式件准入判据（件/示例分档线）**：①**行为骨架预置、呈现全参数化**——预置逻辑与状态（校验流程、提交态、筛选状态管理、分页数据流），长相零主张：只吃语义 token＋shadcn 原语组装（机制/呈现分离既有律；风格支持＝#518 风格层裁完后预置件零改动换装）；②**默认零配置可用**——不改就能出现在切片里（否则执行体每次先理解再改造，即新的耗时源）；③**改造三通道封顶**——定制只走参数/文案覆盖/wrapper 包一层、不碰内部；验收句＝**改造到目标风格成本必低于新写**，做不到的候选降级为栈规则集纯示例（只教做法不给件）。

**布局/导航不预置整壳**：单一化防线画在「结构」之下——平台写入应用壳（sidebar＋topbar＋content）则所有 Demo 一张脸且最难挣脱（结构先于内容）；竞品无一预置布局壳（v0 starter 只预接 provider/字体/全局样式＝token 层最小件）。应用壳惯用法（仪表盘壳/营销页/内容站三类典型）进栈规则集示例，执行体用 shadcn 原语自行组装、结构随 PRD（现状 baseline 无布局文件＝维持零改动）。

**支付示意件不预置**：应用开发中支付占比不高（用户裁定；四家竞品仅 Lovable 做成内置件、因其接真 Stripe）；ADR-0050 推迟清单「支付不真扣款」语义已自然承载——执行体遇 PRD 含支付自做示意级假 checkout。未来高频证据出现，走健壮件「增补＝运营动作」既有通道再议。

**复用纪律（防重造/防大改）**：沿用健壮件三层机制（写入/lint/协议教用法）扩到模式件，新增**基座件不改约**——预置件内部文件不得编辑，定制只走参数/文案覆盖/wrapper；校验＝文件级检测（基座件路径清单、执行体不得写这些路径，实施形态随切片定）。告知通道单源：**栈规则集＝基座能力清单唯一正本**（run 派发时拼入工作区 AGENTS.md、随基座 tag 换版），执行体工作协议只留指针句；不进技能形态——技能层住方法论（换流派即变），基座能力清单是工程事实、双正本必漂移（技能审核指南双向边界）。

**lint 拆半让路（ADR-0050 验证面让路的延伸）**：基座强制档 lint（拦裸写）从「阻断＋修轮＋失败链」降级为「收口照扫、违规只记录标注」（标注进收尾卡/差异摘要、用户可见），不喂修轮、不触发失败、不间接升档；补运营开关做回滚保险（#442 verify 开关同款先例——避免未来再收紧时又要发版）。预置档已是目标形态（#471：不触发修轮、如实标注不动）。设计规范 lint（#296 token 合规）**不动**——它是「预置件吃语义 token」的机械防线、语义本就是软形态（有限重试一轮、仍违规如实标注）。残余风险＝裸写访问层无超时可能挂死，由机器探活三件套（唯一收口硬判据）兜底——「能打开不白屏」仍硬保，属有意识取舍（用户裁定「只要不影响系统呈现体验就可以」）。

**新预置件美学纪律（与 #518 的衔接面）**：一切新预置件（模式件/未来件）只吃语义 token、禁裸色禁任意值——机制/呈现分离既有律、三态 UX 件同款；#518 裁决风格层（生成式设计语言/主题族/skill/模型面）后，预置件零改动自动吃上新语言，衔接即成立。

**不动项**：示例数据维持 ADR-0050 不前置（本票不重开）；图片能力下放不进本票（并入 #518 裁决面，ADR-0026 备案触发器通道不变）；设计规范 lint、整轨终验开关现状不动。

## Considered Options

- **支付示意件进首批**——否决（用户裁定）：应用开发中支付占比不高；推迟清单「支付不真扣款」已承载语义，执行体自做示意级走得通；高频证据出现走「增补＝运营动作」既有通道。
- **布局/导航预置整壳**——否决：结构先于内容、所有 Demo 一张仪表盘脸且最难挣脱（单一化风险最大件）；竞品无一预置布局壳。
- **模式件纯栈规则集示例、不进 baseline**——否决：零配置可用打折（照抄组装仍有理解与改造成本，恰是「比新写还耗时」的温床）；baseline 有 `components/robust` 先例、构建期狗粮门保件质量、tree-shaking 消未用。
- **模式件进技能形态**——否决：技能层住方法论，基座能力清单是工程事实——同一事实双正本必漂移（技能审核指南双向边界）；栈规则集已是设计好的通道（ADR-0035 机制三层之③）。
- **首批清单闭门造长单**——否决（用户裁定「看看哪些常用功能」）：频率判据的最硬证据是现网已生成应用本身；首批只圈双高两件，其余盘点占比回来再定进退。
- **lint 全面停用**——否决：砍的是修轮循环与失败链（耗时反复实源），不是扫描本身；架构约束扫描保留为复用纪律的机械防线（只降级为标注、维持静态单次）。
- **强制档 lint 维持阻断修轮现状**——否决（用户裁定）：lint 是前面耗时与问题反复的大头（11-12 复演 7 升档全 lint 族实证）；三硬底线由探活三件套硬保，裸写超时缺失属可容忍残余风险——「只要不影响系统呈现体验」。
- **业务能力件按「平台预置」扩张（支付/通知做成平台件）**——否决：功能域永留执行体（ADR-0035 边界不变）；预置扩张走高频通用模式、不走业务能力。

## Consequences

- 实施切片三片（票内清单、不建票）：①首批模式件两件进 baseline（件＋行为契约测试、镜像 tag 换版）＋栈规则集扩容（模式件用法节＋纪律句＋应用壳惯用法示例）；②lint 让路改造（`RobustKitLintAppService` 强制档降级为标注＋运营开关）＋基座件不改约检测（文件级路径清单）；③盘点轮（现网应用模式占比→候选清单进退校正，与 ADR-0050 对照轮同班次顺路）。
- ADR-0035 补记（lint 档语义修订＋预置判据扩档）；ADR-0050 补记（验证面让路延伸至 lint 修轮面）。
- CONTEXT.md：新增「模式件」词条（平台内部语言区）；「修轮」「基座健壮件」词条现状句随实施切片同步改写（词条不超前于代码——修轮触发面收窄至样式合规、强制档阻断语义消失）。
- #518 票内备注：图片能力下放并入裁决面（ADR-0026 备案触发器通道不变）。
- 本票纯文档面收口（零代码变更、无 live 类可跑、后台接口零变更，声明）。
