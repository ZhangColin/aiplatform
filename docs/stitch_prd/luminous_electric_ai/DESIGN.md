## Brand & Style

This design system establishes an ultra-refined, optimistic light-mode aesthetic designed for state-of-the-art AI orchestration and developer-centric intelligence platforms. Moving away from sterile monochrome and unyielding stark whites, it infuses the user interface with atmospheric translucency, morning mist cool-tones, and energetic chromatic electricity.

The design movement synthesizes modern structural minimalism with precision glassmorphism and subtle optical luminosity—evoking the pedigree of Stripe, Linear, and modern generative AI workbenches:
- **Atmospheric Clarity:** Warm morning-blue gradients, frosted glass layers, and dew-fresh surfaces create depth without relying on harsh shadows or aggressive boundaries.
- **Electric Vitality:** Electric indigo and hyper-cyan/mint accents inject kinetic intelligence, signaling generative computation, active workflows, and system precision.
- **Micro-tactility:** Frosted panels, hairline borders with chromatic reflections, and layered ambient light halos provide a tactile, forward-looking product presence.

## Colors

The palette operates in an atmospheric light mode where crisp contrast is balanced by chromatic temperature. Deep slate-inks replace flat blacks, and layered morning-tint neutrals replace harsh flat whites.

### Foundation & Surfaces
- **Canvas Base (`#F8FAFC`):** The primary canvas substrate, soft and cooling on the eyes.
- **Dawn Container (`#F0F4F8`):** Recessed layout containers, inactive segments, and grouped track regions.
- **Morning Mist Surface (`#EFF6FF`):** Tinted structural layers, AI prompt bubbles, and active navigation nodes.
- **Violet-Tinted Highlight (`#F5F3FF`):** Ambient accent surfaces, generative response panels, and spotlight zones.

### Structural Hairlines
- **Subtle Blue Border (`#E0E7FF`):** Luminous boundary for interactive cards, containers, and elevated modals.
- **Slate Soft Border (`#E2E8F0`):** Secondary dividers and structural grid rules.

### Typography & Inks
- **Primary Ink (`#0F172A`):** Deep oceanic charcoal for titles, primary numerals, and focal headers.
- **Secondary Ink (`#1E293B`):** Body typography, active tabs, and primary controls.
- **Subdued Ink (`#475569`):** Explanatory paragraphs, table values, and field labels.
- **Faint Ink (`#64748B`):** Metadata, keyboard hints, placeholders, and inactive states.

### Core Signals & Accents
- **Primary Electric Indigo (`#4F46E5` to `#2563EB`):** System catalyst for generative processing, primary CTAs, and active focus boundaries.
- **Mint Teal (`#06B6D4`):** Secondary intelligence signal for telemetry, token velocity, and AI output tags.
- **Emerald Active (`#10B981`):** High-confidence states, verified deployments, and active agent execution.

## Typography

The typographic system is built on **Geist** for crisp, contemporary geometry and **JetBrains Mono** for payload inspection and code syntax. 

- Use tightened negative letter-spacing on headline scales (`-0.015em` to `-0.03em`) to create an authoritative, architectural presence.
- Always activate tabular figures (`font-variant-numeric: tabular-nums`) on all numbers, latency metrics, monetary charges, and execution monitors to preserve strict column alignment.
- When rendering Chinese or CJK scripts, fall back smoothly to `PingFang SC` while preserving font-weight calibration.

## Layout & Spacing

The layout operates on a standard 4px/8px rhythmic baseline coupled with a 12-column fluid responsive grid.

- **Desktop (≥ 1280px):** 12-column grid with `1.5rem` (24px) gutters and `2rem` (32px) outer canvas margins. Sidebars occupy a fixed 240px rail with an optional 360px collapsible context inspector.
- **Tablet (768px – 1279px):** 8-column layout with `1rem` (16px) gutters and `1.5rem` (24px) margins. Sidebars collapse to icon rails or off-canvas drawers.
- **Mobile (< 768px):** 4-column single-flow layout with `1rem` (16px) margins and bottom-anchored actions.

Stack gaps inside components use strict semantic spacing:
- Use `space-xs` (4px) for micro-indicators and icon-label pairings.
- Use `space-sm` (8px) between form inputs and field labels.
- Use `space-md` (12px) for intra-card content sections.
- Use `space-lg` (20px) for container padding and card grid separations.
- Use `space-xl` (32px) for view header separation and major section demarcations.

## Elevation & Depth

Visual hierarchy is constructed through luminous glassmorphic layering, subtle ambient color diffusion, and translucent surface stacking rather than muddy dark drop shadows.

- **Level 0 (Canvas Base):** Solid `#F8FAFC` substrate with a subtle, non-distracting radial background glow (`radial-gradient(ellipse at top, #EFF6FF 0%, transparent 60%)`).
- **Level 1 (Frosted Cards & Panels):** Glassmorphic surface built from `rgba(255, 255, 255, 0.75)` with an `8px` to `12px` backdrop blur (`backdrop-filter: blur(12px)`), encapsulated by a 1px solid border (`#E0E7FF`). Ambient shadow: `0 2px 8px -2px rgba(79, 70, 229, 0.05), 0 1px 3px rgba(15, 23, 42, 0.04)`.
- **Level 2 (Hover & Promoted Toolbars):** Background `rgba(255, 255, 255, 0.9)`, border `rgba(79, 70, 229, 0.25)`, elevated ambient glow: `0 8px 20px -4px rgba(79, 70, 229, 0.08), 0 4px 6px -2px rgba(15, 23, 42, 0.03)`.
- **Level 3 (Command Dialogs & Floating Drawers):** Background `rgba(255, 255, 255, 0.94)` with `backdrop-filter: blur(16px)`, border `1px solid #E0E7FF`, projected drop shadow: `0 20px 30px -8px rgba(15, 23, 42, 0.08), 0 10px 14px -6px rgba(79, 70, 229, 0.06)`. Modal scrim uses `rgba(15, 23, 42, 0.2)` with a `4px` blur.

## Shapes

The shape philosophy blends modern architectural precision with smooth, welcoming contours:

- **Interactive Controls (Buttons, Inputs, Triggers):** Standardized to `0.5rem` (8px). This creates structured, professional geometry with soft mechanical tactile warmth.
- **Cards, Panels & Grouped Containers:** Standardized to `rounded-lg` (`1rem` / 16px) or `rounded-xl` (`1.5rem` / 24px) for outer viewport frames, reinforcing a polished application canvas.
- **Badges, Status Chips & Floating Notification Pills:** Formed as full-pill silhouettes (`rounded-full` / 9999px) to contrast against rectilinear cards and layouts.
- **Hairline Borders:** Maintain a crisp 1px stroke on borders with zero inner pixel bleed. Never use 2px structural borders; visual prominence is achieved with color and glow instead of thickness.

- **Primary Kinetic Button:** Linear gradient from `#4F46E5` (Electric Indigo) to `#2563EB` (Tech Blue) at 135deg. Text is `#FFFFFF` with `label-md` weight. Subtle inset top highlight: `inset 0 1px 0 rgba(255, 255, 255, 0.25)`. Glow shadow on hover: `0 4px 14px 0 rgba(79, 70, 229, 0.35)`.
- **Secondary Glass Button:** Translucent `#FFFFFF` at 85% opacity, text `#0F172A`, 1px border `#E0E7FF`. Hover: background `#EFF6FF`, border `#C7D2FE`.
- **Ghost Action Button:** Transparent background, text `#475569`. Hover: background `#F0F4F8`, text `#0F172A`.

### Status Badges & Gradient Accent Pills
- **AI Running / Processing:** Pill container with background `linear-gradient(135deg, rgba(79, 70, 229, 0.08), rgba(6, 182, 212, 0.12))`, text `#4F46E5`, 1px border `#C7D2FE`. Paired with a pulsating 6px cyan core dot.
- **Success / Healthy:** Background `rgba(16, 185, 129, 0.1)`, text `#047857`, 1px border `rgba(16, 185, 129, 0.25)`, 6px emerald status dot.
- **Attention / Latency Warning:** Background `rgba(245, 158, 11, 0.1)`, text `#B45309`, 1px border `rgba(245, 158, 11, 0.25)`.

### Input Fields & Search Bars
- **Base Style:** Background `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(8px)`, 1px border `#E2E8F0`, text `#0F172A`, placeholder `#64748B`.
- **Focus Interaction:** Border transitions to `#4F46E5`, paired with an ambient perimeter halo: `box-shadow: 0 0 0 3px rgba(79, 70, 229, 0.15)`.

### Cards & Container Modules
- **Default Card:** Surface `rgba(255, 255, 255, 0.8)`, border 1px solid `#E0E7FF`, border-radius `1rem` (16px), shadow `0 2px 8px -2px rgba(79, 70, 229, 0.04)`.
- **Spotlight / Feature Card:** Displays a soft radial background glow on top right (`radial-gradient(circle at 100% 0%, rgba(6, 182, 212, 0.08) 0%, transparent 50%)`).

- **Active State:** Solid gradient background `#4F46E5` to `#2563EB`, border `transparent`, with an internal white check SVG glyph. Focus ring matches the 3px indigo halo.
