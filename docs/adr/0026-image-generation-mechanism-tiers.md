# 出图机制档位：三路定档、HTML 介质统一、四供应商工具面接入与按张计量

设计能力线出图机制档位裁决（2026-10-03，#275，承 ADR-0023 定位、ADR-0024 载体、ADR-0025 过程形态，依据 docs/research/2026-10-03-image-gen-mechanism-facts.md 三路并评）定案：**分线定档**——设计交付线（logo/图案/海报/插画）＝图片生成模型＋代码出图**双工具并存**、设计执行体按设计物语义自选（「写实氛围还是排版型海报」是语义判断，档位表落提示词层约定、不做代码级硬路由分类器）；UI 设计稿线＝**零图片模型**（可交互实现正身，六家对标无一以位图为设计稿主形态）；系统内资产（logo 进系统）＝**零新出图**（设计产物文件直接进构建上下文，SVG 在 web 原生可用——是搬运不是生成）。**介质统一 HTML**：代码出图的现实介质＝HTML/CSS 排版（icon 库/图表库/inline SVG 做子件），不是手写 SVG path——对标六家与 stitch 画布（浏览器渲染的 HTML）无一以 SVG 为设计主介质，LLM 手写 SVG 高审美不可行；SVG 只作 vector 原生物件（logo 源文件）的正身。介质统一使代码出图与 UI 设计稿、系统构建同源（皆 HTML，基座原生形态）。**渲染截图（chromium）入图**：落位＝位图出口管道（HTML→PNG 保真快照/衍生资产/下载件）——设计交付线卖平面设计物、位图件是交付刚需（stitch 产物 HTML＋截图双形态同构）；与画布呈现分家——设计稿 tab 呈现走用户浏览器 iframe live 渲染（零 chromium），服务端渲染只管出口；代价＝dev 镜像压缩体积 +0.4–0.5 GB、Playwright 6–7 周一版强绑定，DEV_IMAGE 升版重建走既有机制；SVG→PNG 走 resvg/sharp 零浏览器旁路（vector 原生物件特价路径），扛不了 HTML 主线。**图片模型供应商＝四家全接**：阿里 DashScope（qwen-image 系列，中文文字第一梯队、0.18 元/张，AgentScope v2.0.1 原生扩展内置文生图工具件＝接入最顺）＋智谱（CogView-4 0.06/GLM-Image 0.10，最便宜）＋火山（Seedream 4.5 0.25 起，方舟 images 端点 OpenAI 同形、baseUrl 覆写——未实测）＋OpenAI（GPT Image，国际质量档——用户自备 key，区域合规责任归用户侧运营）；三家国内供应商商用条款明文「权利归用户可商用」；适配器模式对偶博查先例（base-url＋key＋按供应商选适配器），key 落 .env.local 不进 git；测试先行序＝智谱/火山/OpenAI（key 现成）→阿里（key 后补）。**实现口径＝工具面非模型面**：core Model 接口纯 chat，图片模型不进 ModelRef 白名单（零改），是工具件背后的 API；三动点＝pom 依赖＋`AgentToolkitSupplier` 向设计执行体发放＋图片呈现管道（归 #276）；系统轨构建执行体不发（系统内资产来自设计线搬运、构建不出图；备案触发器＝无设计线的系统单真要出图）；供应商返回图 URL 24h 时效→**平台即时转存、URL 不直透用户**（转存实现归 #276）。**审核与滥用**：v1 技术防线＝供应商 API 审核拦截（国内三家自带），责任口径如实归平台（条款「责任归调用方」＝平台）——平台用户条款把生成物权利传递给平台用户（运营侧文档落笔，零机制）；平台不自建审核层、不加提示词拒答专项（备案触发器＝供应商拦截漏放成真问题）；AI 标识水印备案（触发器＝面向公众上线或法规明确要求）。**失败/质量兜底零新概念**：技术失败（API 报错/审核拦截/超时）＝执行体内自动重试（有限上界，对偶 #63 置备重试先例），重试不产新候选、最终失败该稿如实标记失败态；质量不合意＝一律走改稿→新候选代（ADR-0025 候选横向分代本身就是变体机制，多稿即横向变体）；重试各次照计平台成本。**按张计量**：单价表档位维度扩为「token 档位与按张」、平台成本词条随改（用量＝token 或张 × 事件时点生效单价）；图片生成＝新计量事件与模型调用事件并列进成本观测；开行/改价/关行语义零改。**多模态 LLM（视觉输入）本票零需求**：文生图是独立 API 服务非 LLM、代码出图是纯文本 LLM 写 HTML、截图是渲染；下游两处可能引入——#277 图→规范提炼（可选增强，规范文件路线纯文本兼容不依赖它）与参考图改稿增强；用户口径＝国内外双支持、key 自备（国内 GLM-4.5V/qwen-vl-max/doubao-vision，国际 Gemini/Claude/GPT），接入归各自票。

## Considered Options

- **代码级硬路由分类器（按设计物类别分流三路）**——拒绝：类别判断本身是语义判断（写实氛围海报 vs 排版型海报），交 LLM；工具发放＋prompt 档位约定即达，分类器是投机性复杂度。
- **SVG 为代码出图主介质**——拒绝：六家对标与 stitch 无一以 SVG 为设计主介质；LLM 手写 SVG path 画高审美平面物不可行（用户同判）；HTML/CSS 排版是证实路径（next/og 先例、基座原生形态）。
- **渲染截图备案缓做（第一步 SVG＋resvg 旁路扛位图出口）**——拒绝：介质既统一 HTML，「SVG→PNG 零浏览器」只覆盖 vector 原生物件；HTML→PNG 唯一保真路是 chromium，平面物位图件是交付刚需。
- **图片模型单供应商起步**——拒绝（用户改判）：四家全接——国内三家商用条款明文、价格带 0.04–0.6 元/张覆盖质量档，OpenAI 补国际质量档；适配器模式使多家接入不增主链路复杂度，换/加供应商零动主干。
- **国际线整体出局（OpenAI/Google 区域条款排除大陆主体）**——部分推翻：OpenAI 仍接（质量档需要、用户自备 key、区域合规责任归用户侧运营）；Google/Anthropic 不接。
- **平台自建内容审核层 / 提示词拒答专项**——拒绝：API 层供应商拦截自带且责任本就归平台；自建是引入新能力级工作量，打磨期无真实漏放证据。
- **独立「重roll/变体」概念**——拒绝：与 ADR-0025 候选横向分代撞语义；多稿机制本身就是变体机制，零新概念。
- **图片模型进 ModelRef 白名单（模型面接入）**——拒绝：core Model 接口纯 chat；工具面接入（工具件发放）白名单零改、呈现管道才是大头（#276）。

## Consequences

- CONTEXT.md 随改：单价表（档位含 token 档位与按张）、平台成本（用量＝token 或张）。
- #276 图片管道票承接全量事实：URL 24h 即时转存（不直透用户）、chromium 入镜像、resvg/sharp 旁路、供应商接入形态实测（方舟同形未实测、智谱 images 形态待核、OpenAI 区域可用性随 key）、「供应商对被拦截请求是否计费」核实。
- #272 图部件备案触发器两条件之一（本票）落地；#276 落地后图部件毕业入交付物包。
- #277 一致性票解锁视角：多模态视觉输入是可选增强非依赖；「图片→结构化规范」提炼机制仍是其核心决策点。
- 成本观测面（#281）将出现按张计量事件；单价表初始化多四行（四供应商图片模型）。
