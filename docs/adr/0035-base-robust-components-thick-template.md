# 基座健壮件收口与厚模板六层终形

基座裁决（2026-11-06，#407 grilling 拍板、#421 实施，spec #416 承 #404 地图决定集首批；依据＝五份调研报告的生产缺陷面归纳，锚案例＝项目 376467559906353574「背词记忆管家」redis.get() 无超时挂死返修两轮）定案：**「每个应用都要写的横切健壮能力」收进基座由平台预置、生成只写功能**——执行体每次手写通用件（会话读取、DB 访问、外部调用超时、错误边界、加载态）写不对就是生产事故，用户首触即撞。

**总界＝机制/呈现分离**：基座件担行为契约（超时、重试、降级、不挂死、不裸泄漏），呈现主权在设计 token 与项目侧——件消费项目 shadcn/设计 token 渲染（只引用语义类、不写死色值）、文案默认可覆盖（props 全量可换），行为统一而长相各随项目。**首批四件套**＝数据访问层（pg/redis 超时＋重试＋降级）、fetch 封装（默认超时＋错误归一）、三态 UX 件（加载/空/错状态切换＋页面级错误边界）、会话存储件（cookie 管理、redis 会话存取带超时降级、密码 scrypt 哈希）；**登录页面/流程/角色模型永留执行体**（平台不收功能域）。

**机制三层**（#421 落地第一层，②lint 两档与③工作协议条目归 #425）：①**阶段 0 起跑前平台确定性写入**——四件套与测试跑道随基座工程模板（镜像内置 `/opt/baseline`）在容器初始化时首次就位，不走运、不耗模型迭代（同设计 token 物化先例的保证性语义）；栈规则集由平台在 run 派发时按健壮件在场探针拼入工作区 AGENTS.md——节内容描述的件与探针锚（`src/lib/robust/data-access.ts` 在场与否）同批就位，**存量项目不回补**（件不在场＝节不拼入，不指路不存在的文件）。②收口 lint 两档（强制档拦数据访问/fetch 裸写、预置档拦会话件自写不拦不用）。③执行体工作协议「用基座件、禁裸客户端」条目。

**测试跑道＝模板自证**：Vitest 配置（happy-dom＋plugin-react＋`@` 别名对齐 tsconfig paths）与自测骨架随模板预置，四件套自带行为契约测试（超时/重试/降级/不挂死/文案可覆盖/语义 token 消费）——执行体写/跑测试零 setup；模板测试随镜像构建验证（基座层 `pnpm install && pnpm test` 狗粮门，红＝镜像构建失败）。**厚模板六层终形**＝镜像运行时＋工程模板＋基座健壮件＋测试跑道＋栈规则集＋设计 token 注入（前两层与 token 注入在位，本 ADR 补后三层）。

**演进口径**：只收横切通用件（判据＝每应用都要写、与具体功能无关）；基座模板内容变更一律随镜像 tag 换版（单源，DEV_IMAGE 常量）；基座增补＝运营动作（生产返修缺陷面归纳反哺）；存量项目不回补。

## Considered Options

- 执行体继续每次手写通用件（提示词教写法）——拒绝：写不对就是生产事故（锚案例返修两轮实证），提示词非保证性机制。
- 健壮件由平台在 run 派发时逐文件 exec 写入（同设计 token 四件物化形态）——拒绝：件含 npm 依赖（vitest 等），现场 pnpm install 耗时且依赖网络运气；镜像预装是既有承诺（工作区初始化＝模板就位、非项目内现场 install），件随模板走。
- 栈规则集无条件拼入所有工作区 AGENTS.md——拒绝：存量项目件不在场，节指路不存在的文件即误导（「用 data-access」诱导执行体自写件——恰是要拦的形态）；探针条件拼入把「不回补」口径结构性地落地。
- 登录页面/流程也收进基座——拒绝：功能域不过界（charting 轮用户裁决「像团队一样预置框架与基础功能」的边界正在于此）；会话/密码只收原语。
- 测试跑道选 jest——拒绝：vitest 与 vite/Next 生态同栈、配置更薄；jest 需 transform 编排更重。
- 模板测试只在工作区内跑、不进镜像构建——拒绝：模板自己不吃狗粮则行为契约随依赖漂移静默腐烂；构建期验证红＝构建失败，零额外 CI 面。
- 存量项目回补四件套——拒绝：改存量项目工作区＝侵入生成产物且件与项目已写代码可能冲突；生产缺陷面归纳后走运营动作反哺基座、新项目自然获得。

## Consequences

- CONTEXT.md 词条「基座健壮件」「基座工程」已随 #407 spec 预落（六层组成＋首批清单＋机制三层口径），本 ADR 为实施正本。
- 基座镜像 tag 0.14→0.15（模板内容变更单源换版）；旧裸客户端出口 `src/lib/db.ts` 随数据访问层吸收删除（模板不再内置绕过健壮件的起点）。
- 基座模板结构断言进既有模板测试缝（classpath 正本）；AGENTS.md 拼节判据进生成/更新 run 起手资产就位用例族。
- #425（lint 两档＋工作协议条目）以本 ADR 机制三层为前提；#426（路由信号）文件面信号须排除基座文件基数（模板增重的联动面）。
- 演进＝运营动作反哺（生产返修缺陷面归纳→增补件随 tag 换版）；schema/种子数据收口第二批观察（spec #416 Out of Scope）。
