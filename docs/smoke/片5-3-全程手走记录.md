## 三、走查中揪出并修复的缺陷

1. **#34 BA 自答泄漏（阻断需求环的漏洞）**：`ask_user` 的答复经 answer key 注入 tool call input → 持久化到会话 → 模型从回放学得自问自答（复现：9 问后 12 次 ask_user 里 11 个编造答案）。修复：答复改走 **block metadata**（模型不可见通道），inputSchema 移除 answer 键，`checkPermissions` 恒 ASK。回归守卫见 `AskUserToolTest.given_answer_key_in_input_when_check_permissions_then_still_ask`。
2. **后台脚本 `backoffice-quote.sh` 源码包两处 bug**（脚本与实现一致性，零残留终检项）：
   - `$out` 后紧跟全角括号 `（`，bash UTF-8 下把多字节字节读进变量名 → `set -u` 报 unbound variable（package 从未跑通过）→ 改 `${out}` 定界。
   - `cmd_package` 用 `set --` 复用位置参数装 curl 头，`$1`（orderId）被清成 `-H`，URL 变 `/api/backoffice/orders/-H/source-package` → 404 订单不存在。修复：orderId 先落 `local oid`，后续引用 `$oid`。
3. **删 `AgentscopeHitlSmokeTest`（base 层真内核 HITL 冒烟）**：其 settle/JSON 往返守卫（等待点 body → 重建 ConfirmResult → resume）与生产路径同口径，已由 `BaInterviewSmokeTest` 端到端承接（`answerQuestion` 内部走同一 `answeredToolCall` 重建路径，并含 #34 守卫 input 不含 answer）。原冒烟依赖 `DEEPSEEK_API_KEY`（CI 内 `assumeTrue` 跳过），属冗余守卫，随 #34 修复一并收敛。
