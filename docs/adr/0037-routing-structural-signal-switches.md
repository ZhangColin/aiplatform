# 路由结构性信号开关化：文件面/规模标签默认关、仅失败重试升档

模型路由信号面裁决（2026-11-11，#454 用户裁决；承 ADR-0030 模型路由、#426 信号面修订）。现状事实：路由三件信号（历史失败/文件面/规模标签）中，结构性两件（文件面阈值、规模标签映射）在生产实测暴露系统性偏差——2026-11-11 同需求项目对照（旧信号开）：文件面 19→50 只涨不落，seg2 起段段升 pro（pro 448/906 次调用）；而两条失败重试升档（seg0/seg2 flash 首尝失败）证明失败信号有真实质量价值。生产已用现有旋钮 interim 关停（`routingFileCountThreshold=999999`、`routingEscalatingSizeLabels=[]`，#426 空映射语义），本裁决把 interim 态转正为信号级开关。定案：

**结构性信号默认关**：文件面/规模标签两信号各持信号级开关（`routingFileCountSignalEnabled`／`routingSizeLabelSignalEnabled`，prj_agent_configs 扩展列 V58，PUT /api/backoffice/agent-configs/executor 同一通道、留痕同机制）——缺省 false＝关＝对应信号**不参与升档判定**；true＝恢复对应判据（阈值/映射旋钮照旧生效）。**失败重试信号不受两开关影响、常开**——生成全程用 flash，只有失败重试才升档（seg 重试时升 `routingStrongModelId`，缺省 pro）。

**理由**：文件面只增不减（工作区文件数过阈值后永不回落），「越大越强模」激励错位——升档放大逐片最大耗时桶（llm 等待），越升越慢；规模标签同理是主智能体计划时的静态自报，非实现期真实复杂度。真正该做的是**让每段只访问受影响的文件**，文件面自然有升有降——这是长期方向（文件访问面收敛：按切片依赖图 `depends_on` 传递闭包裁剪文件面统计与上下文装载），**本裁决只做开关不拆功能**。

**生命周期口径（用户原话）**：先都关掉观察，效果不好随时开回来；确认没这两个信号也没问题，再拆功能。

**观测兼容**：收尾卡 `closing.modelTier.signals` 照旧全量留档——关了的信号留观测值（fileCount/sizeLabel 照采照记）并加 `fileCountSignalEnabled`/`sizeLabelSignalEnabled` 参与标记，对照实验数据不断档。文件面探针不受开关影响照常采集（观测价值大于 exec 成本）。

## Considered Options

- **维持结构性信号常开、只重校阈值**——拒绝：只增不减是结构性缺陷非阈值标定问题，重校阈值只是把错位推迟到更晚的段。
- **直接拆文件访问面收敛（本裁决的长期方向）**——拒绝：牵动面大（路由判定、上下文装载、观测基线三线同改），先关后拆——开关落地后跑对照轮量化「影响面文件面」与全量文件面的曲线差异，再议是否恢复结构性判据。
- **用路由总开关 `routingEnabled` 一并关停**——拒绝：总开关＝钉死位（人工档恒生效、失败重试升档也关）；用户裁决要的是「失败重试升档照常工作」，必须信号级开关。
- **沿用空映射/超大阈值的旋钮 hack 当永久方案**——拒绝：运营误配阈值即悄悄恢复信号（无显式语义位），且 hack 不留「信号关」的显式观测标记——开关列缺省 false 使「关」成为自文档化缺省。

## Consequences

- 智能体运营配置值面再扩两列（结构性信号开关），GET/PUT/traces 同扩；admin 仓（semgravio-admin）配置读/写面与 traces 快照随 API 增量对齐（对接票互链口径）。
- 新缺省＝开关关＋无失败全 flash：同需求复演应见全段 `modelTier.modelId=flash`；失败后重试升档行为不变——验收锚。
- 生产现网 interim 态（999999/[]）在新开关落地后归一化为开关关（一次配置变更，留痕）。
- 路由判定快照 signals 增两枚参与标记（`fileCountSignalEnabled`/`sizeLabelSignalEnabled`）——观测面可区分「信号在场」与「信号参与判定」，对照实验可算反事实。
